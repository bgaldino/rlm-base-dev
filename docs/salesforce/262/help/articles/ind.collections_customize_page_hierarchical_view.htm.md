# Customize Lightning Pages to View Collection Plans and Related Records in a Hierarchical View

To enable collections specialists to view collection plans and their related records, add the Hierarchical View component to the financial account record page.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: View product and edition availability.
USER PERMISSIONS NEEDED
To customize a Lightning record page:	

Collections and Recovery Admin permission set

AND

Modify All Data permission

AND

Customize Application permission

AND

OmniStudio Admin permission set

AND

FSC Sales permission set

Collections specialists can manage collection activities more efficiently by viewing related financial accounts, collection plans, and collection plan items all at once on the financial account record details page. They can view collection plans and related records up to three levels.

From the App Launcher, find and select Collections.
Click Financial Accounts, and open a financial account record page.
Click , and then select Edit Page.
Drag the Hierarchical View component from the Components panel to the Lightning page canvas location where you want to position the component on the record page.
In the Properties pane, select first-level related list and second-level related list.
For example, on the financial account record page, the first-level related list is Collection Plans, and the second-level related list is Collection Plan Items. Your collections specialists can view all collection plans and collection plan items linked to a financial account on its record details page.
