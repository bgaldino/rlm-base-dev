# Permission Sets Combination for Salesforce Contracts

Many of the tasks requires that you understand permission set combinations. The section provides a detailed mapping of the Salesforce Contracts personas with the required permissions sets.

The table lists the combination of Salesforce Contracts, DocGen, and Omnistudio permission sets that are required for certain Salesforce Contracts features.

PERSONA	SALESFORCE CONTRACTS PERMISSION SET	DOCGEN PERMISSION SET	OMNISTUDIO PERMISSION SET
CLM Admin User	CLM Admin User	DocGen Designer	Omnistudio Admin / Omnistudio User
CLM Runtime User	CLM Runtime User	DocGen Designer	Omnistudio Admin / Omnistudio User
Partner Community User	CLM Digital Experience Partner User	DocGen Runtime Community User	Omnistudio User
