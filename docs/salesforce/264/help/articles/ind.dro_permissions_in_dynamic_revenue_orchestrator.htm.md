# Permissions in Dynamic Revenue Orchestrator

Review the permissions required for Dynamic Revenue Orchestrator.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Developer Editions of Revenue Cloud
Permission Sets in Dynamic Revenue Orchestrator
Permission sets grant users access to specific objects, fields, and features, and are the recommended way to manage permissions. Dynamic Revenue Orchestrator (DRO) provides standard permission sets for setting up DRO, designing fulfillment, managing fulfillment at run time, and submitting transactions. Assign the permission set that matches each user's role.
Provide Dynamic Revenue Orchestrator Access
Assign the appropriate permission set to give users Dynamic Revenue Orchestrator access, and review the permissions included in a permission set.
Create Fulfillment Users for Order Orchestration
During fulfillment, Dynamic Revenue Orchestrator (DRO) uses the permissions associated with the fulfillment user rather than those of the user who submits an order. You can specify a different user for certain orchestration tasks, but generally, the permissions default to the fulfillment user. Select the fulfillment user from the Dynamic Revenue Orchestrator Settings pane.
