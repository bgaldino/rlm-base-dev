# Quickly Design Document Templates Without a Managed Package

Use Design Document Template to design and generate documents from templates in Microsoft Word (.docx), Microsoft 365 Word (.docx), and Microsoft PowerPoint (.pptx) formats. Existing customers who use Omnistudio or Industries managed packages can also use the capabilities of this new template designer.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

Who: To use Design Document Template, users need the DocGen Designer permission set.
