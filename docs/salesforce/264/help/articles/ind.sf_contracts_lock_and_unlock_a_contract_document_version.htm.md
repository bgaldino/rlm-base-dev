# Lock and Unlock a Contract Document Version

To lock and unlock a contract document version, it must be active.

You can lock the active contract document version. Typically, you use this feature to ensure that no one changes the contract document. Only an admin or the user who locked the document can unlock it.

If an active contract document version is locked, you can unlock it to allow changes.

A contract document version that is not checked in, will be in a lock state, and unlocking it will delete the document.
