# Effortlessly Digitalize Legacy Contracts and Create Contract Records with Contracts AI

Use generative AI to streamline and automate the process of digitizing PDF contracts, and significantly reduce the time and effort required to identify and extract data such as contract fields and clauses. Contracts AI helps minimize the risk of errors that occur during manual data entry. Track and review multiple extractions from a comprehensive user interface.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions with the Contracts AI add-on license. Einstein generative AI is available in Lightning Experience.

Who: To use this feature, users need the Contracts AI User permission set.

Why: Contracts AI helps:

Improve searchability and accessibility, making it easier to locate specific information within contracts.

Minimize the risk of errors by eliminating the need for manual document searches to extract intricate contract details.

Store the extracted details intermittently when the review is in progress, providing users ample time for review.

Create reports for various entities associated with a contract document version record.

Map document fields to various standard fields on a Salesforce object.

Create a contract record and add extracted clauses to the clause library.

How: To enable the Contracts AI setting, from Setup, in the Quick Find box, enter Contracts Lifecycle Management, and then select Contracts AI.
