# Assign Document Playbook Licenses and Permission Sets

Assign the permission set license and permission sets that match each user persona. Designers create and manage playbooks. Contract authors consult playbook guidance during risk analysis.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Performance editions.
USER PERMISSIONS NEEDED
To assign licenses and permission sets:	CLM Admin User
From Setup, in the Quick Find box, enter Users, and then select Users.
Open the user whom you want to assign the permissions.
In the Permission Set License Assignments related list, click Edit Assignments and select Document Playbook.
Save your changes.
In the Permission Set Assignments related list, click Edit Assignments and add the permission sets for each user persona.
PERSONA	PERMISSION SETS
Salesforce admin who creates Document Playbook users	Data Cloud Architect, CLM Admin User, Contracts AI User, and Document Playbook Designer
Playbook designer who creates, activates, archives, or deletes playbooks and assignments	Data Cloud Architect, CLM Runtime User, Contracts AI User, and Document Playbook Designer
Playbook user who only reads playbook content during risk analysis	CLM Runtime User, Contracts AI User, and Document Playbook User
Save your changes.
After you add these permissions, the Document Playbook Settings page appears in Setup.

Complete Turn On Document Playbook Management.
