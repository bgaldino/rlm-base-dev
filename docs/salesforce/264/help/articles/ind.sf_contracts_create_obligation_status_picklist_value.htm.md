# Create Obligation Status Picklist Value

The default obligation statuses are Compliant, Non-Compliant, and At Risk. Configure additional custom obligation statuses. These custom obligation statuses are available when you create and update any obligation.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 


To create a custom obligation status:

	

CLM Admin User

Click Setup | Object Manager.
In the Quick Find box, enter Obligation, and then select Obligation | Field & Relationships.
In Status Picklist Values, click New.
Enter a new obligation status value.
For example, Renewed.
Save your changes.
