# Actions Available for a Section in Salesforce Contracts

The permissible actions for a section depend on whether the section is locked or not. Contract authors, internal reviewers, and external reviewers can’t edit or delete sections that template designers lock.

SECTION STATE	SUPPORTED ACTIONS	DESCRIPTION
Unlocked	

Delete

Edit Properties

	

To delete a section.

To lock a section within contract documents and document templates to prevent unauthorized edits


Locked	

Edit

Delete

Edit Properties

	

To unlock a section.

To delete a section.

To unlock a section within contract documents and document templates to modify the section content.
