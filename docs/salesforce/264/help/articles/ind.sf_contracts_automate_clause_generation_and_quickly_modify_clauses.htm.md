# Automate Clause Generation and Quickly Modify Clauses with Contracts AI

Use Contracts AI to draft legal clauses based on input parameters or user prompts. Automate clause drafting to reduce manual research, minimize stakeholder collaboration, and enhance consistency in language and format.

Where​: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions with the Contracts AI add-on license. Einstein generative AI is available in Lightning Experience.​

Who​: To draft clauses, users need ​the Contracts AI User permission set license.

Why: Contracts AI helps:

Save time by drafting clauses based on user queries or by using parameters such as jurisdiction, involved party, industry or sector, and agreement classification.

Quickly add a clause or alternate clauses to existing clause sets.

Enhance clause generation precision by using the feedback feature. You can give a thumbs-up or thumbs-down rating.

Instantly modify or replace a clause content with clauses drafted by the generative AI.

How: To enable the Contracts AI setting, from Setup, in the Quick Find box, enter Contract Lifecycle Management, and then select Contracts AI.
