# Define Field Mappings to Create and Update Contracts from sObjects with an Intuitive UI

Contract Admins can now use the new user-friendly mapping interface to easily create and update contracts from sObjects. Streamline operations across various use cases by using context service as an integrated method to create and update contracts from any sObject. Users can also benefit from the ContractsContextDefinition mapping that's shipped, which includes mappings for extracting data from Opportunity, Order, and Quote to facilitate contract creation and updates.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

Who: To create context use case mappings, users need the CLM Admin User permission set.

Why: In previous releases, Salesforce Contracts offered support only for XML-based field mapping to facilitate the updating and creation of contracts from sObjects. Customers could use the out-of-the-box XML field mappings for Opportunity, Quote, and Order or establish custom field mappings to create and update contracts.

How: From Setup, in the Quick Find box, enter Context Service, select Context Service Settings, and then turn on Context Definitions. In the Quick Find box, enter Contracts Lifecycle Management, select General Settings, and then turn on Context Service for Salesforce Contracts.
