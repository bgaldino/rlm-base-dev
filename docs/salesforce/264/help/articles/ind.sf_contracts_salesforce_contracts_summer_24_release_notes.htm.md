# Salesforce Contracts Summer '24 Release Notes

Added functionality for Customer Community Plus users, DocGen Designers, Contract authors, and Contract Administrators.

Customer Community Plus users can collaborate on document review, track e-signature status, and access signed documents. DocGen Designers can import and export document templates from one Salesforce org to another. Contract authors and admins can facilitate various functions within contract lifecycle management by using the new invocable actions. Contract Admins can swiftly define field mappings for creating and updating contracts from sObjects with an user-friendly interface. Add non-standard clauses to the clause library for reuse. Use the enhanced contracts digitalization process to tailor extraction prompts for improved accuracy. Use the enhanced Design Document Template page to filter templates and and access all template versions.

Add Non-Standard Clauses to the Clause Library To Ensure Reusability
Clause users can use the intensive review process to submit non-standard clauses, such as clauses drafted by Contracts AI or marked as clauses for the designer's review. Once clauses are added to the library, contract users can then reuse them anytime, across various contract documents and templates.
Collaborate with External Users in the Contract Management Process
Collaborate on contract management with a wide range of B2B and B2C external users through an interactive portal. External users can review documents, track e-signature status, and access the signed contract documents.
Define Field Mappings to Create and Update Contracts from sObjects with an Intuitive UI
Contract Admins can now use the new user-friendly mapping interface to easily create and update contracts from sObjects. Streamline operations across various use cases by using context service as an integrated method to create and update contracts from any sObject. Users can also benefit from the ContractsContextDefinition mapping that's shipped, which includes mappings for extracting data from Opportunity, Order, and Quote to facilitate contract creation and updates.
Access Versions of a Template and Filter Templates More Intuitively
The enhanced Design Document Template page lets you view the latest template versions, filter by Template Type, Usage Type, or Clone Only, and access full version history. Click Show All Versions to see all versions in descending order.
Export and Import Document Templates Between Salesforce Orgs
Deploy document templates across multiple customer orgs through a managed package. The managed package stores the exported document templates from the source org, such as sandbox. You can import the managed package containing document templates into the target org, such as your production org.
New Invocable Actions in Salesforce Contracts
Use the ten new invocable actions in Salesforce Flows to perform actions such as the creation of document versions, contract creation and updates, dynamic contract actions, and e-signature functionalities to manage contract lifecycle.
Contracts AI
To customize, and streamline the process of digitizing PDF contracts, leverage the enhanced Einstein generative AI feature. Now, you can significantly reduce the time and effort required to identify and extract the required contract field values.
