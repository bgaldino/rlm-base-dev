# Document Generation for Quotes

Create formatted quote documents that meet your business and customer requirements. Revenue Cloud supports three document generation options: legacy quote PDF generation, Document Builder, and CLM Document Generation. Choose an option based on the document experience, scale, and features that your business requires.

Choose a Document Generation Option
Use these guidelines to choose an option for generating quote documents.
Generate a Quote Document with CLM Document Generation
Generate a large-scale PDF document from a quote. Select a document template, preview the generated PDF, and access the saved document from the quote.
Document Builder for Quotes
Use Document Builder to design professional quote documents in Revenue Cloud.
Generate a Quote Document with Document Builder
Preview, generate, and email quote PDFs from the quote page. Share details about completed work with your customers in real time.
Capture Signatures on Web and Mobile App
Add a digital signature to a quote PDF in the office or in the field. Signatures help make quote PDFs legally binding and professional. Capture signatures on the web or in the Salesforce mobile app.
Set Up Document Builder for Quotes
Turn on Document Builder to begin creating customized, dynamic quote templates that align with your business practices.
Create a Quote Template with Document Builder
Design a template that defines how information appears in quote documents. Use the template to generate customized quotes for your customers. Start with the default quote template or a blank template, and add standard Document Builder components that contain relevant quote details.
