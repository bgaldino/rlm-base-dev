# Enable Salesforce Contracts Console App

From Setup, the Salesforce admin has to make the Salesforce Contracts Console App visible for profiles. Users can then access the app from the App Launcher.

You're logged into the Salesforce instance as a System Admin.

USER PERMISSIONS NEEDED	 
To enable the Salesforce Contracts Console App:	CLM Admin User
REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
From Setup, in the Quick Find box, enter profiles, and then select Profiles.
Click Edit next to a profile that you want Salesforce Console App to be visible.
To make the app visible.
Go to Custom App Settings.
In Salesforce Contracts (standard__SalesforceContracts), select Visible.
To set the app as default.
You can select one default app. To set Salesforce Contracts Console App as the default app.
Go to Custom App Settings.
In Salesforce Contracts (standard__SalesforceContracts), select Default.
The default app appears when users log in for the first time.
Save your changes.
