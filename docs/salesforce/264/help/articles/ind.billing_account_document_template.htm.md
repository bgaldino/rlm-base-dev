# Assign an Invoice Document Template to a Billing Profile

Give an account its own invoice PDF by assigning a document template to its billing profile. Billing uses that template for batch and individual invoice PDFs.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Developer Editions with the Revenue Cloud Billing license. Contact your Salesforce account executive for more information.
USER PERMISSIONS NEEDED
To assign an invoice document template:	

Billing Admin permission set OR Billing Operations User permission set

AND

DocGen User permission set

AND

DocGen Designer permission set

From the App Launcher, find and select Billing Accounts.
Open the billing account.
Select the invoice template to use for the account.
Save your changes.

Batch and individual invoice PDFs use the billing profile template in the same resolution order. See Generate Individual Invoice PDF Documents.
