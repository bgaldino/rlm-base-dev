# Create a Document Playbook by Uploading a File

Create a playbook, activate its first version, and assign the playbook to a Contract record type in a single action. Use this task when your playbook document is final and you don't need to iterate on drafts before making the playbook active.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Performance editions.
USER PERMISSIONS NEEDED
To create and activate document playbooks:	Document Playbook Designer

Before you begin:

Make sure your Salesforce admin has completed document playbook setup and sharing. See Set Up Document Playbook.
Make sure you have a PDF, DOCX, or XLSX guidelines file no larger than 100 MB.
Make sure your guidelines are organized into clear sections for rules, preferred positions, fallback clauses, and approval guidance.
NOTE To create the playbook shell first and iterate on the version before activation, see Create a Document Playbook and Activate a Version.
From the App Launcher, find and select Document Playbooks.
Click Upload Playbook.
Attach a PDF, DOCX, or XLSX file up to 100 MB.
Enter the playbook details.
Save your changes.
Salesforce creates the playbook in Draft, creates a version linked to the uploaded document, activates the version and parent playbook, and creates an assignment for the target object and record type.
