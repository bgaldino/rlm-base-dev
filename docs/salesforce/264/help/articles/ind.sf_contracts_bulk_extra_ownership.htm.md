# Change Ownership of Bulk Extraction Results

As a Salesforce admin managing extractions for a team, assign extraction results to the appropriate users for review and contract creation by changing ownership.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Professional, Enterprise, Unlimited, and Developer Editions
USER PERMISSIONS NEEDED
To change ownership of extraction results:	

CLM Admin User

AND

Contracts AI User

AND

Data Cloud User

From the App Launcher, find and select Contract Extraction Results.
Select one or more records.
Click Change Owner.
Select a new owner.
Save your changes.
Assign the new owner Contracts AI User, CLM Runtime User, and Data Cloud User permission sets.
Assign the owner at least one contract record type through either their profile or the Record Type Access settings in their permission set.
