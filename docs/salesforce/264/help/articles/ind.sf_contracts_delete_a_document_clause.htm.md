# Delete a Document Clause

You can delete a clause that is in Draft state. Ensure all the alternate clauses are deleted before deleting the last main clause version.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 
To create, edit, and search document clause sets and document clauses:	

ClauseUser

OR

ClauseDesignerUser

OR

ClauseDigitalExperienceUser

From the App Launcher, find and select the Document Clause Sets tab.
Select the clause that you want to delete.
Click Delete.
To confirm, click Delete.
