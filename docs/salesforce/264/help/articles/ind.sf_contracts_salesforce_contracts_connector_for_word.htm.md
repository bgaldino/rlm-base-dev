# Design Document Templates in Microsoft 365 Editor

The Salesforce Contracts Connector for Word add-in provides a quick and efficient way to design and maintain document templates and also, create and edit contract documents by using the Word features in Microsoft 365.

The add-in also provides an efficient design experience that simplifies the overall process of creating document templates and contract documents. This is accomplished by simplifying the search process for elements like clauses within the templates, by preventing syntax errors, and by providing a smooth editing and saving experience.

ATTENTION When integrating macros into your Microsoft Word and Microsoft 365 document templates, exercise caution and conduct thorough testing to mitigate potential security risks. Salesforce doesn't assume responsibility for any issues that may arise due to the use of macros.
Create Templates by Using Microsoft 365 Word in Document Template Designer
Document template designers can use the rich capabilities of the Microsoft 365 to create document templates.
Create Section in Document Template
When designing a document template, the template designer can define sections within the document to structure and organize the content more effectively.
