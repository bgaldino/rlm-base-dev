# Connect with Salesforce Contracts Console App

The Salesforce Contracts Console serves as a one stop solution for contract management features such as homepage, contracts, and clauses.

Salesforce Contracts console app enables users to efficiently create and manage contracts by consolidating all the relevant features into a single, user-friendly platform. Users can connect to a specific record page using either the standard contract record page or the console app that provides a streamlined and intuitive user experience. You can access the Salesforce Contracts console app from the App Launcher.
