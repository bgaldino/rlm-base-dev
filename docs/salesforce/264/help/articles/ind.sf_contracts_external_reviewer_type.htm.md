# External Reviewer Type in Salesforce Contracts

Salesforce Contracts enables different types of external reviewers with varying access permissions to collaborate on the documents.

REVIEWER TYPE	LINK WITH AZURE	LINK WITH SALESFORCE	SALESFORCE CONTRACTS FOR WORD ADD-IN VIEW
Guest User	Yes	No	Guest Add-in
Customer Community Guest User	Yes	No	Guest Add-in
Linked User	Yes	Yes	Core Add-in
Direct Email	No	No	No Add-in
NOTE Multi tenant external reviewers are not supported.
