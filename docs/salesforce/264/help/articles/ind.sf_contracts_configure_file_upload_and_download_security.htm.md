# Configure File Upload and Download Security for Salesforce Contracts

To view the generated documents in the Documents tab of a contract you must update the file upload and download security settings for .docx and .pdf file types.

From Setup, in the Quick Find box, enter File Upload and Download Security.
Click File Upload and Download Security.
Click Edit.
Select Hybrid or Execute in Browser for .docx and .pdf file types.
Save your changes.
