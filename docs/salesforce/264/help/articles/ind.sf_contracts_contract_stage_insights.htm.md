# Contract Stage Insights in Salesforce Contracts Analytics

Embed this dashboard on the Contract page to analyze the number of days a contract remained in a specific stage. Compare contract duration with the global average time and get valuable context for performance evaluation.

Use the Contract Stage Insights dashboard to view:

The average number of days that the contracts remain in specific stages.

The stages where contracts tend to stay longer than the global average time.

The stages where contracts tend to progress more quickly than the global average time.

The duration of contracts in specific stages compared to the overall global average time.

The patterns or areas for improvement based on the comparison of contract duration with the global average time.
