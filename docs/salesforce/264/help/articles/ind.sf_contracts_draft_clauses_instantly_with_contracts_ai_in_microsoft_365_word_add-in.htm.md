# Instantly Draft Clauses in Microsoft 365 Word Add-in with Contracts AI

Use Contracts AI to draft and insert legal clauses directly in the Microsoft 365 editor based on input parameters or user queries. Accelerate clause creation for document templates and contract documents, and add reusable clauses to the clause library.

Where​: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions with the Contracts AI add-on license. Einstein generative AI is available in Lightning Experience.

Who​: To draft clauses in the Microsoft 365 editor using Contracts AI, users need​ a Contracts AI User permission set license.

How: To enable the Contracts AI setting, from Setup, in the Quick Find box, enter Contract Lifecycle Management, and then select Contracts AI.
