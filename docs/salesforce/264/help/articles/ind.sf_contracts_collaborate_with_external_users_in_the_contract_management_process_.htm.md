# Collaborate with External Users in the Contract Management Process

Collaborate on contract management with a wide range of B2B and B2C external users through an interactive portal. External users can review documents, track e-signature status, and access the signed contract documents.

Where: This change applies to Lightning Experience in Enterprise, Professional, Unlimited, and Developer editions.

Who: To access Salesforce Contracts, external users need the ContractMgmtCCPlusUser permission set license.
