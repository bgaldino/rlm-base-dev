# Edit Electronic Signature Envelope Configurations for Standard and Custom Objects

You can edit the default reminders and expiration timeframes for envelopes submitted for e-signature from the Electronic Signature Envelop Config.

From Setup, in the Quick Find box, enter Electronic Signature Envelope.
Click Electronic Signature Envelope Config.
Click the dropdown arrow next to the configuration that you want to edit and click Edit.
Edit the required details.
Save your changes.
