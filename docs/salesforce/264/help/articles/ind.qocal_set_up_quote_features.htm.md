# Manage Quotes in Revenue Cloud

Run these configuration procedures to optimize the quote management lifecycle and document generation within Revenue Cloud. Prioritize the setup of quote line item imports and opportunity synchronization to accelerate record creation while maintaining data alignment across your sales pipeline. By stabilizing these foundational dataflows, you make sure that complex elements like bundles and attributes transition accurately from preliminary offers to finalized orders.

Use advanced professional tools like the Document Builder and Einstein Generative AI to streamline proposal sharing and deal overviews. Configure automated order conversion. Segment quotes into multiple independent orders by using groups or specific fields. This segmented approach provides the flexibility required to manage complex fulfillment and billing needs. These integrated features help the sales teams to refine proposals efficiently and move from customer acceptance to draft orders with a single click.

Quote Management Lifecycle
Sales representatives use quotes as preliminary offers to propose products and pricing to customers. This lifecycle involves discovering products, entering quote details, and managing revisions before converting a final proposal into an order.
Quote Line Item Imports
Importing quote line items from a CSV file accelerates the quoting process by eliminating manual data entry for large volumes of products. Revenue Cloud uses Transaction Management components to process these imports, ensuring data consistency across multiple product types and currency models.
