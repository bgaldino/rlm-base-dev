# Enable Salesforce Contracts

Grant users access to create and manage contracts by using Salesforce Contracts.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 
To enable Salesforce Contracts:	

CLM Admin User

From Setup, in the Quick Find box, enter Contract Lifecycle Management, and then select General Settings.
Turn on Salesforce Contracts.

After enabling Salesforce Contracts, complete the remaining setup steps. See Get Started With Salesforce Contracts.
