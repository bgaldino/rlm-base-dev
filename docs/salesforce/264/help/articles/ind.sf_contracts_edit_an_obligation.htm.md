# Edit an Obligation

The obligation manager and obligation assignee assigned to an obligation can update the obligation. The obligation assignee can only update the status and the status change reason.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 


To update an obligation:

	

Obligation Manager permission set

OR

Obligation Assignee permission set

From the App Launcher, find and select Obligations.
Click the obligation that you want to update.
Select Edit from the dropdown.
Make the necessary changes to the obligation fields.
The Status Change Reason is a mandatory field for obligation status change.
Save your changes.
