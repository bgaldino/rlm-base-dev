# Comparing Contract Document Versions

Compare a contract's current version with any previous version to identify differences introduced during redlining. The comparison highlights content modifications and table edits. Initiate comparisons from the contract record page or the Microsoft 365 editor.

Compare Two Versions of a Contract Document from the Contract Record Page
Use the Compare Contracts feature to analyze differences between document versions. You get a clear, side-by-side comparison of the modifications, including edits, additions, and deletions.
Compare Two Versions of a Contract Document from the Microsoft 365 Editor
Compare contract document versions directly from the Microsoft 365 editor during negotiations. Check out a document version, open the Salesforce Contracts Connector add-in, select the version to compare against, and review highlighted changes.
Limitations of Contract Comparison Previewer
The limitations of the contract comparison feature include support for only DOCX documents. The feature also has a cap on the maximum preview size, default page count limits, and variation in preview generation time. If the document preview fails, especially for larger files, you can download the comparison document to view the differences.
