# Supported Browsers and Devices for Salesforce Contracts Connector for Word Add-In

The add-in supports the Android, Microsoft Windows, and iOS operating systems, and the latest stable browser versions of Apple® Safari®, Mozilla Firefox, and Google Chrome™.

NOTE With Summer ‘23, the add-in supports only Office on the web. The add-in doesn’t support desktop versions of Office.
Laptop Browsers

Salesforce supports these browsers. Make sure that your browsers are up to date. Other browsers or older versions of supported browsers aren't guaranteed to support all features.

WARNING Salesforce isn't responsible for any sharing of data based on this change from default settings.
NOTE The browser vendor defines “latest.” Check with your browser vendor to determine the latest version available. Salesforce supports only 64-bit version browsers in Google Chrome and Mozilla Firefox.
