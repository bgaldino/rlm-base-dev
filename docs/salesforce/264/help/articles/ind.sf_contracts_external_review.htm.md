# External Review in Salesforce Contracts

Contract authors can send documents to external parties for evaluation, feedback, and suggested changes. After external reviewers provide their input, the author incorporates the feedback and checks in the final document version.

The online and offline review modes describe the approaches to initiating and managing external reviews throughout the contract lifecycle. Online reviews take place electronically within the Salesforce application or via connected systems, offering both private and nonprivate review options. In contrast, offline reviews occur outside Salesforce, where the contract is downloaded, shared, and reviewed. Feedback and changes are later reconciled in Salesforce by using the import method.

NOTE If you're using the default state model, the contract must be in Negotiating state to get the Initiate External Review action.
Initiate Online External Review
Contract authors can send documents for external review in Private or Non-Private mode. Non-private reviews use the Microsoft 365 add-in with shared visibility. Private reviews create a sanitized document copy that protects internal data, granting ownership only to external reviewers until the review is complete.
Initiate Offline External Review
Contract authors can initiate an offline external review process from Salesforce.
Reviewer Actions in External Reviews
An external reviewer can initiate the review process by clicking the review link in the email received from the contract author. This occurs when the reviewer is added in the Initiate External review process.
View Review Status and Cancel External Review
Contract authors can check the review status and check whether all reviewer changes and comments are addressed.
