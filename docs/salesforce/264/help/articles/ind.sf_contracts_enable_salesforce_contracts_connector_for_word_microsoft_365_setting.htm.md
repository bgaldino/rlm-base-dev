# Enable Salesforce Contracts Connector for Word (Microsoft 365) Setting

To continue to use the Microsoft 365 Word features after you upgrade to Winter ‘24, you must enable the Salesforce Contracts Connector for Word (Microsoft 365) setting.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

When: Salesforce Contracts enforces this update in Winter '24.

How: To enable this setting, from Setup, in the Quick Find box, enter Document Generation, and then select General Settings.
