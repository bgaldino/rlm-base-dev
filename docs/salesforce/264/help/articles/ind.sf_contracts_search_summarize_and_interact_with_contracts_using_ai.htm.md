# Search, Summarize, and Interact with Contracts Using AI

Use Contract Search with AI to query and analyze contract documents using natural language. You can view matching contracts, ask questions, summarize content, and preview or download contract documents.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Performance editions.
USER PERMISSIONS NEEDED
To use contract search:	

CLM Runtime User

AND

Contracts AI User

AND

Prompt Template User

Click Search Contracts on the Contracts list page.
Click Got it.
Enter your query in the Start your search box using natural language.
Example: "Show me all contracts where the payment term is 30 days and there is protection against failure of delivery due to an upcoming storm in the state of California"
Press Enter to view the search results with matching contract segments.
To generate a context-aware summary of the contract document, click Summarize this. The summary is based on the context of your search query and highlights key information from the document.
NOTE The first two results are summarized automatically. You can see Summarize this only for the remaining results.
To ask a question about a specific contract document, click Ask Contract Questions. Enter your question in natural language to get AI-powered answers based on the contract's content.
NOTE The Ask Contract Questions icon is visible if a contract agent is configured. See Set Up a Contract Agent.
To preview or download the contract document:
Click the More Actions icon.
Select Preview Document or Download Document.
