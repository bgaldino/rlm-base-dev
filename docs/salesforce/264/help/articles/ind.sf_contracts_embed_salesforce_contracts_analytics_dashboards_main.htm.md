# Embed Salesforce Contracts Analytics Dashboards

Give more users visibility into the insights in Salesforce Contracts Analytics app by embedding its dashboards in Lightning Experience pages.

USER PERMISSIONS NEEDED	 
To create and save Lightning pages in the Lightning App Builder	Customize Application
To view Lightning pages in the Lightning App Builder	View Setup and Configuration
REQUIRED EDITIONS
Available in: Lightning Experience
Available with Salesforce Contracts for an additional cost in: Enterprise, Unlimited, Professional, and Developer Edition

For more general instructions on embedding CRM Analytics dashboards to lightning pages, see Embed Dashboards in Lightning Pages. Here's how to add the Salesforce Contracts Analytics dashboard to your org’s home page.

In your Salesforce Contracts Analytics app, click the app navigation menu and select Home.
Click the app navigation menu, and select Accounts.
Click  and select Edit Page.
From the list of standard components, drag CRM Analytics Dashboard onto the page canvas.
Specify the component's attributes.
Save your changes and exit Lightning App Builder.
