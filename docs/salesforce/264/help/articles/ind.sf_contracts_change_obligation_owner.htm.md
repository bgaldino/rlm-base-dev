# Change Obligation Owner

Only the obligation manager who created the obligation or the current obligation manager assigned to the obligation can change the ownership of the obligation to another obligation manager.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 


To change the obligation manager:

	

Obligation Manager permission set

From the App Launcher, find and select Obligations.
Click the obligation that you want to update.
Select Change Owner from the dropdown.
Select the new obligation manager.
To send a notification via email to the new obligation manager, select Send notification email.
Click Submit.
