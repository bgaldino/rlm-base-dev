# Prerequisites For Setting Up State Models, State Transitions, and Actions

To set up State Models, State Transitions, and Actions, as a system administrator, make sure that you have the required licenses and permissions.

Ensure that your org has these licenses:

ContractManagementAddOn

DocGenDesigner

OmnistudioDesignerAddon

Confirm that your org has the Contract Lifecycle Management User permission set license. If not, contact your Salesforce account executive. Assign yourself the Contract Lifecycle Management User permission set license.
