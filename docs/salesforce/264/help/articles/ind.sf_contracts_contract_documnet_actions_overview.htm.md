# Use Salesforce Contracts Application

Contracts may go through multiple iterations. Each time there is a change, a new version is recorded. Contract document operations can be performed on contract document versions.

Create and Manage Contracts in Salesforce Contracts
Create contracts from opportunities, orders, quotes, or any standard or custom object that has field mappings configured.
Contract Authoring in Microsoft 365 Editor
You can add clauses from a clause library to simplify the contract authoring and editing process by making it easier to locate and add relevant clauses and to update the existing clauses.
Design Document Templates in Microsoft 365 Editor
The Salesforce Contracts Connector for Word add-in provides a quick and efficient way to design and maintain document templates and also, create and edit contract documents by using the Word features in Microsoft 365.
E-Signatures for Salesforce Contracts
Finalize deals from anywhere with electronic signature (e-signature). E-signature integration lets business teams prepare, negotiate, manage, and sign contracts electronically instead of processing physical documents.
Obligation Management
Associate obligations with contracts to track contractual commitments. Assign each obligation to an owner, monitor compliance status, and receive automated notifications when deadlines approach.
Keep Data in Sync by Using Data True-Up
Use Data True-Up to keep contract documents and Salesforce records aligned. View token values from both sources, identify differences, and update either the document or the record without losing redlines. This bi-directional sync maintains accuracy throughout the contract lifecycle.
Comparing Contract Document Versions
Compare a contract's current version with any previous version to identify differences introduced during redlining. The comparison highlights content modifications and table edits. Initiate comparisons from the contract record page or the Microsoft 365 editor.
Connect with Salesforce Contracts Console App
The Salesforce Contracts Console serves as a one stop solution for contract management features such as homepage, contracts, and clauses.
How Document Playbook Works
A document playbook captures the guidelines, acceptable clause language, and fallback positions that legal and contract teams follow during contract negotiations. When a contract author runs a risk analysis on a contract in the Microsoft 365 Word add-in, Salesforce compares the contract against the active playbook and highlights deviations, escalation paths, and nonstandard language. Use document playbooks to manage versioned negotiation guidelines that Contract Risk Analysis uses to evaluate contract changes against your organization's standards.
How Contract Risk Analysis Works
Contract Risk Analysis compares each modified clause in a contract against your approved playbook. After a reviewer makes changes to a version of the contract, the author runs the analysis using the Microsoft 365 Word add-in. A generative AI model scores each modified clause, explains the risk, and recommends the mitigation content to add to the contract.
