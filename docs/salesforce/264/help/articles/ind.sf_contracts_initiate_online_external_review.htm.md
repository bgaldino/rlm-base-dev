# Initiate Non-Private External Review

Contract authors can initiate an online non-private external review process from the Microsoft 365 add-in. In non-private reviews, the contract author can view all changes and comments made by external reviewers during the review process and can accept or reject them.

REQUIRED EDITIONS

Prerequisite: Make sure that the contract is in the negotiating state for the Initiate External Review action to be available.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS
NEEDED
To initiate an external non-private review:	Microsoft 365 Word User
Open the contract document version that you want to send for external review.
Select the action as Initiate External Review.

Select Initiate an Online Review, and then click Next.
Select Non-Private Review, and then click Check Out Document.
The contract document version is automatically checked out and the Open in Microsoft 365 button becomes active.
Click Open in Microsoft 365.
The contract document version opens on a new tab in the Microsoft 365 editor.
Click the Salesforce Contracts for Word add-in on the Home tab.
Click Add External Reviewers.
Search for and select reviewers by their name or email address.
You can also add the email address of the user that you want to add as an external reviewer.
Select the access type for reviewers, such as edit and view, and then click Add.
NOTE The view access type grants read-only access to the reviewers, while the edit access type enables the reviewers to modify the document, and to edit and delete the comments.
Click Send Email to start the review process.
An email with the link to the contract document is sent to the reviewers.
Review a Contract Document in Non-Private External Review Mode
After the contract author sends the contract for external review, reviewers open the document, make tracked changes and comments, and mark their review as complete. The review status updates in Salesforce, where the contract author checks review status and check the document back in when all reviewers complete their review.
