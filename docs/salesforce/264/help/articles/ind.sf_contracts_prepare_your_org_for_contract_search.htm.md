# Prepare Your Org for Contract Search

To prepare your org, enable Data Cloud, assign the required permission sets, and turn on Einstein Generative AI.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Performance editions.
USER PERMISSIONS NEEDED
To configure contract search:	

Data Cloud Architect [Home Org]

OR

Data Cloud One [Companion Org]

AND

CLM Admin User

AND

Contracts AI User

Enable Salesforce Contracts to support contract document ingestion. See Enable Salesforce Contracts.
Turn on Data Cloud to ingest and index contract data. See Turn On Data Cloud.
Assign Data Cloud Architect, CLM Admin User, Contracts AI User, and Prompt Template Manager permission sets to admins to use contract search. See Manage Permission Set Assignments.
Assign CLM Runtime User, Contracts AI User, and Prompt Template User permission sets to users who need access to contract search. See Manage Permission Set Assignments.
Enable Einstein Generative AI to support natural language search. See Set Up Einstein Generative AI.
Make sure Check In Document File Type and Auto Generate Doc File Type are set to Word, PDF. See Contract Type Config Settings.
