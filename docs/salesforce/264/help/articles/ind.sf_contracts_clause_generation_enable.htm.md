# Turn On Clause Generation in Contracts AI

Generate clause content by using Contracts AI. The standard prompt template runs automatically during clause generation and defines how content is generated.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Professional, Enterprise, Unlimited, and Developer Editions
USER PERMISSIONS NEEDED
To turn on Clause Generation:	

CLM Admin User

AND

Contract AI Clause Designer

AND

Prompt Template Manager

From Setup, in the Quick Find box, enter Contracts AI, and then select Clause Generation.
Turn on Clause Generation.
Customize Clause Generation in Contracts AI
To tailor the generated clause content, modify the standard prompt template by using Prompt Builder. This step is optional and intended for advanced use cases for using Prompt Builder.
