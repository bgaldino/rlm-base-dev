# Define New Contract Object State Values

From the Object State Definition, you can update your contract object state definition.

Using the App Launcher, open Object State Definition.
Select the contract object state definition that you want to update.
For example, select the default Contract Lifecycle Management.
From the Details tab, clear the Active checkbox and save your changes.
From the Related tab, scroll to the Object State Values section, and click New.
Enter the exact status name that you created in Create New Contract Status Values.
Enter a description for the new status value and save the changes.
