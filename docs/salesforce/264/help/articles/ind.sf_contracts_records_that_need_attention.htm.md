# Records that Need Attention in Salesforce Contracts Analytics

The Records that Need Attention dashboard highlights incomplete contracts, clauses, and template documents prioritized by value and age. Embed this dashboard on the Sales Administrator Home page.

Use the Records that Need Attention dashboard to view:

The contracts that are currently incomplete and require immediate attention based on their priority.

The impact of values of the contracts in their prioritization for attention and resolution.

The contracts that have been pending for the longest duration since their creation and need urgent action.

The clauses and template documents that need attention, and in what order of priority are they considered.
