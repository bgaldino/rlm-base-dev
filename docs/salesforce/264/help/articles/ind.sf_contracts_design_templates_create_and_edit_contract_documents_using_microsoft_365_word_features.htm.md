# Design Templates and Create and Edit Contract Documents with Microsoft 365 Word Features

The Salesforce Contracts Connector for Word add-in integrates Microsoft 365 Word with Salesforce Contracts. Design and maintain document templates, create and edit contract documents, and insert content such as clauses from the Clause Library directly in the Microsoft 365 editor.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

Who: Users need either Microsoft Word 365 or Microsoft 365 Word Digital Experience User permission set licenses.

Why: In previous releases, the Salesforce Contracts application didn’t support direct editing of document templates or contracts. To make changes, the designer had to download the document, make edits, and then upload the document back to Salesforce. Now you can easily edit and add data from Salesforce by opening the Microsoft 365 editor from the template designer or contract document version in Salesforce. Then, instantly sync the changes to Salesforce.

Add-in capabilities include these features:

Integrated editing experience while accessing Salesforce data for authorized users.

Quick access to the Salesforce Clause Library for authorized users.

Sync changes made in the Microsoft 365 editor instantly to Salesforce.

Unified view of all the clauses within a document in a single pane.

Use of Microsoft 365 Word features to format documents.
