# Facilitate Collaborative Negotiations with External Reviewers

Initiate contract reviews directly from the Salesforce Contracts Connector for Word add-in to eliminate document downloads and reduce email reliance. Add or remove editors, monitor individual review status, and track changes and comments from each reviewer.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

Who: Contract authors need the Microsoft 365 Word or Microsoft 365 Word Digital Experience User permission set license to initiate the external reviews. External reviewers can either be a customer community user or any user with Azure Guest user credentials.
