# Extract the Clause Category ID for Clause Approval

Use the clause category ID to define the clause approval process for a clause category.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED
To extract the clause category ID:	Clause Designer User
From Setup, in the Quick Find box, enter Clause Category.
Click Clause Category Configuration.
A list of clause categories appears.
Click the clause category that you want to define the clause approval process for.
Extract the clause category ID from the URL. Copy the text starting from 0z.
For example, 0zMxxxxxxxxxxxx.
Note the clause category ID.
Use the ID for defining the clause approval in step Define a Clause Approval Process Name.
