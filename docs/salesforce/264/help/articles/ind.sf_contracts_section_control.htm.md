# Configure Section Access Control Permissions in Salesforce Contracts

The admin sets up and assigns the required permissions for template designers and contract authors to use section access control during internal reviews.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Professional, Enterprise, Unlimited, and Developer Editions
USER PERMISSIONS NEEDED
To create a permission sets:	Manage Profiles and Permission Sets
To assign permission sets:	Assign Permission Sets
From Setup, enter Permission Sets in the Quick Find box, and then select Permission Sets.
Click New, enter a name for the permission set, and save it.
In the permission set, click System Permissions, and then click Edit.
Search for and select the required permissions.
For template designers, select View All Profiles.
For contract authors, select View All Profiles and Manage Users.
Save your changes.
Click Manage Assignments, and then click Add Assignments.
Select the users, and then click Assign.
Click Done.
