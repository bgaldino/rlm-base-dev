# Document Template Filtering for Salesforce Contracts

Using custom logic, you can filter the templates that you want to display for a contract based on the contract type. You can configure a filtering class for each contract type.

Based on the filtering custom logic, only the set of templates that match the custom logic displays in the templates drop down under the generate action in the Documents tab of a contract. For more information, see Use Custom Document Template Filtering.
