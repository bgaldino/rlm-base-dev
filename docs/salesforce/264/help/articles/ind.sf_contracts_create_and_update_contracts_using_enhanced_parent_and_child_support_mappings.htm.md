# Create and Update Contracts with Enhanced Parent and Child Mappings

Salesforce Contracts uses field mappings to create and update contracts from standard or custom objects. In addition to parent-to-parent and child-to-child mappings, Salesforce Contracts supports parent-to-child and support-based mapping methods for greater flexibility.

IMPORTANT

Existing customers who upgraded to Summer '23 or later releases must delete their existing field mappings and create a new structure to continue using the create contract and update contract features from standard or custom objects.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

Who: To deploy the field mappings, users need CLM Admin User permission.Tto create and update contracts from standard or custom objects, users need CLM Runtime User or CLM Digital Experience Partner User permissions.
