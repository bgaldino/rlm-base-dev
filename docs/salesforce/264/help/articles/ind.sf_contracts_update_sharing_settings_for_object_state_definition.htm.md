# Update Sharing Settings for Object State Definition in Salesforce Contracts

To make the Object State Definition records created by a user, accessible to all the users within an org, you need to update the sharing settings.

From Setup, in the Quick Find box, enter sharing.
Click Sharing Settings.
Click Edit.
Provide these access to your Object State Definition:
OBJECT	DEFAULT INTERNAL ACCESS	DEFAULT EXTERNAL ACCESS (IF NEEDED)
Object State Definition	Public Read Only	Public Read Only
Save your changes.
