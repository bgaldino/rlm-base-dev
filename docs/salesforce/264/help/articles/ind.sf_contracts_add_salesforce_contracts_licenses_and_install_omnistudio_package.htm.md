# Add Salesforce Contracts Licenses and Install Omnistudio Package

Add the required Salesforce Contracts licenses to your org. If your implementation uses Omniscript-driven state transitions, Omnistudio document generation, or Data Mapper integrations, also install the Omnistudio package.

Salesforce Contracts uses Omnistudio for guided Omniscript actions during contract state transitions, client-side document generation, and Data Mapper field mapping. If your org already includes Omnistudio or you don't use these features, skip the Omnistudio installation steps.

What Omnistudio Adds
Document generation
Use the Omnistudio template designer for client-side generation, Integration Procedure-driven templates, and advanced token support beyond what Design Document Templates offers natively.
State model Omniscript actions
Build guided interactions, such as approval wizards or signature flows, that trigger during contract state transitions.
Data Mapper integrations
Use Data Mappers as an alternative to Context Service for mapping fields during contract creation and updates.
Steps

Get the relevant Salesforce Contracts licenses added to your org by a Salesforce Administrator. For details about the applicable Salesforce Contracts licenses, refer to Salesforce Contracts Licenses.

[Optional] Prepare to Install the Omnistudio Package.

[Optional] Install or Upgrade the Omnistudio Package.
