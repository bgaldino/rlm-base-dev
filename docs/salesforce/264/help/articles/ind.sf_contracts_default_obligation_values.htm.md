# Default Obligation Values

The default obligation management includes predefined states, status and supported obligation parties for obligations.

Obligation fields and their default values that support obligation management.

FIELD	VALUES	DESCRIPTION
State	

On Hold

Active

Inactive

Expired

	Specifies the state of the obligation. You can configure additional obligation state values. The default values are On Hold, Inactive, Active, and Expired.
Status	

Compliant

Non-Compliant

At Risk

	Specifies the status of the obligation.
Party	

First Party

Other Party

	Specifies the party who executes or delivers the obligation.
