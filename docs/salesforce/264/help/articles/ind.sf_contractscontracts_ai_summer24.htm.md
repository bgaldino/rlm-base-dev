# Contracts AI

To customize, and streamline the process of digitizing PDF contracts, leverage the enhanced Einstein generative AI feature. Now, you can significantly reduce the time and effort required to identify and extract the required contract field values.

Tailor Your Default and New Field Prompts for Effective Data Extraction with Contracts AI
Users can modify the default field descriptions by using the enhanced contracts digitization feature. Enhance the accuracy of field value extraction from a file based on predefined fields. Map and extract values for any field in the file by providing precise and clear descriptions for generative AI to extract values. Use Context Definitions to create extraction templates.
