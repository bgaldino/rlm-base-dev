# Salesforce Contracts Analytics Post-Installation Steps

To see your data in the dashboards after you install Salesforce Contracts Analytics, you must schedule your app to refresh.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
Schedule the Salesforce Contracts Analytics App
Select a time outside normal work hours so the data refresh doesn’t interrupt business activities.
Verify Permissions for Salesforce Contracts Analytics
When you turn on CRM Analytics for your org, a default Analytics Integration User is created. This user accesses the data within Salesforce when the recipe is used to bring data in as datasets to CRM Analytics.
Create Other Versions of Salesforce Contracts Analytics
After the initial instance of Salesforce Contracts Analytics is auto-created, you can create other versions via Analytics Studio so that your team members can use the version that meets their needs. You can create as many versions as you need.
Embed Salesforce Contracts Analytics Dashboards
Give more users visibility into the insights in Salesforce Contracts Analytics app by embedding its dashboards in Lightning Experience pages.
Salesforce Contracts Analytics Dashboard Attributes
Salesforce Contracts Analytics includes dashboards that you can embed and access in Lightning Experience pages.
