# Journey Map Example by User Type in Salesforce Contracts

Salesforce Contracts support multiple personas such as contract user, and contract administrator, to deliver role-specific experiences.

Here’s an example journey map that illustrates the experience of a sales executive, an admin, and a channel partner in Salesforce Contracts.

PERSONA	USE CASE	PERSONA JOB DESCRIPTION


CLM Runtime User

For example, Sales Executive

	

Create a sales contract.

Negotiate with customers and get their e-signature.

Manage post-signatory contracts such as amend, renewal, and performance contracts.

Oversee multiple contracting processes.

	

Steve, the sales executive collaborates to create contracts and manages the contract lifecycle and customer relationship. It includes:

Contract authoring.

Generate contract documents for an opportunity, order, quote, and Salesforce custom objects.

Collaborate with internal team members.

Online negotiation with customers.

Maintain versioning, and redlining of the document.

Intimate recipients for e-signature.

Manage contract lifecycle from authoring to termination.




CLM Admin User

For example, Sales Operations Admin

	

Create contract templates.

Manage document and e-signature configurations.

Configure contract lifecycle and state models.

	

John, the sales operations admin configures the contract management setup and configurations. It includes:

Configure contract templates, contract documents, and contract types.

Configure e-signature integration.

Create contract approval workflows.

Manage contract terms, contract lifecycle definition, and state models.

Ability to update existing contracts, such as - lock, unlock, and cancel.




Contract Partner Community User

For example, Channel Partner

	

Create sales contracts.

Manage contracts.

	

Stacy, the channel partner, creates and manages contracts for the provider's partner community. It includes:

Select template and generate contracts on behalf of service providers.

Seek approvals.

Manage different versions of the contract.

Send contract documents to end customers.

Manage contracts lifecycle with end customers.
