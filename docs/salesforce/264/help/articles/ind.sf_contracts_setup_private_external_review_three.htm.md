# Create a Private External Review Setting

Use the Digital Experience site name to create a private external review setting in the contract type config.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Performance editions.
USER PERMISSIONS NEEDED
To create private external review setting	CLM Admin User
From Setup, in the Quick Find box, find and select Contract Type Config.
Click New.
Enter the values for the compare contract versions contract type config.
In Contract Type, select Default.
In Usage Type, select Document Setting.
In Config Type, select External Private Review Guest Site Name.
In Config Value, enter the URL of the site that you previously created.
See Create a Digital Experience Site for Private Online External Review.
Click Create.

After you've created a private external review setting, then you've to Enable Private Online External Review
