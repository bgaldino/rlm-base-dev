# Export and Import Document Templates Between Salesforce Orgs

Deploy document templates across multiple customer orgs through a managed package. The managed package stores the exported document templates from the source org, such as sandbox. You can import the managed package containing document templates into the target org, such as your production org.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

Who: To export and import document templates, users must have DocGen Designer permission set.
