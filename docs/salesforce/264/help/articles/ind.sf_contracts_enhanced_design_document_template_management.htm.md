# Access Versions of a Template and Filter Templates More Intuitively

The enhanced Design Document Template page lets you view the latest template versions, filter by Template Type, Usage Type, or Clone Only, and access full version history. Click Show All Versions to see all versions in descending order.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

Who: To use Design Document Template, users need the DocGen Designer permission set.

How: Go to Design Document Template and filter templates or click Show All Versions.
