# Enable Salesforce Contracts Analytics

Salesforce Contracts Analytics works seamlessly with existing Salesforce Contracts features. Set up and configure Salesforce Contracts Analytics to access the Salesforce Contracts dashboard and analytics.

The Salesforce Contracts Analytics setup page is available only for the Salesforce admin, Salesforce Contracts admin, and Salesforce Contracts Analytics admin.

From Setup, in the Quick Find box, enter Salesforce Contracts and select Salesforce Contracts Analytics.
To get CRMA analytics admin and Salesforce Contracts analytics admin permissions to set up Analytics, click Assign Permission Set in the Permissions to Set Up Salesforce Contracts Analytics section of the setup page. Assign CRMA Analytics Plus Admin and Salesforce Contracts Analytics Plus Admin permission sets.
To enable CRM Analytics in Salesforce, click Set Up.
NOTE You can check the Salesforce Contracts Analytics app's installation status after steps 2 and 3 are complete from Setup > Auto-Installed App > Requests tab. The Salesforce Contracts Analytics app is available under the Applications tab after the installation is complete. The dashboard is also accessible from the App Launcher via the Analytics Studio > Salesforce Contracts Analytics > Dashboards.
To enable Salesforce Contracts Analytics, click Enable.
To update Salesforce Contracts Analytics to the latest version, click Update.
To assign relevant permissions to the Salesforce admin and users, click Assign Permission Set.
For users who manage the Salesforce Contracts Analytics dashboard, assign the CRM Analytics Plus Admin and Contracts Analytics Admin permission set.
For users who need read-only access to the dashboards, assign the CRM Analytics Plus User and Salesforce Contracts Analytics User permission set.
