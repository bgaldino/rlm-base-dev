# Configure Private Online External Review

CLM admin must complete a few configurations so that contract authors can initiate private online external reviews. It includes creating a Digital Experience site, setting up a contract-type config setting for external review, and enabling the external review feature from the Microsoft 365 and Azure Integration guided setup.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Performance editions.
Create a Digital Experience Site for Private Online External Review
Set up a Digital Experience site for your private external review, customize its layout, and then publish it.
Create a Private External Review Setting
Use the Digital Experience site name to create a private external review setting in the contract type config.
Enable Private Online External Review
If customers use the guided setup for Microsoft 365 and Azure Integration, the admin has to enable the external private review in the Set Up the Auth Provider section. Contract authors can then start private online external reviews.
