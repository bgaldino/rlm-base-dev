# Deploy Salesforce Contracts Connector for Word Add-In App to Users Manually

Through a centralized deployment, Salesforce Admins can deploy and assign the app to all or specific users. Users can then insert the add-in into their Microsoft 365 Word.

USER PERMISSIONS NEEDED	 
To deploy the add-in app to users:	System Administrator with Azure Tenant Administrator access
REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions

You can deploy the add-in from the Microsoft 365 admin center or search for the add-in app in Microsoft AppSource. Salesforce recommends deploying the add-in from the admin center.

IMPORTANT Salesforce Contracts Connector for Word is supported only in the Microsoft 365 web version. It isn’t supported in the Microsoft 365 desktop version.
Deploy add-ins in the Microsoft 365 admin center.
The add-in page opens.
Deploy the add-in from Microsoft AppSource.
Log in to your Microsoft 365 account.
Go to Salesforce Contracts Connector for Word page.
Click Get it now.
Enter your details, and click Get it now.
The Microsoft 365 admin center opens.
Insert Salesforce Contracts Connector for Word Add-In App into Microsoft 365 Word.
