# Draft Clauses with Contracts AI

Use Contracts AI to draft legal clauses based on input parameters or user prompts. Automate clause drafting to reduce manual research and enhance consistency in language and format.

For example, a contract designer can query for a force majeure clause, prompting Contracts AI to generate a clause. The designer can then save the clause as a draft. The designer can also draft alternative force majeure clauses tailored specifically for pandemic-related situations. Add these clauses to the clause library for future use in document templates.

IMPORTANT Generative AI supports drafting clauses only in English.
