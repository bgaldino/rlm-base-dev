# Tailor Your Default and New Field Prompts for Effective Data Extraction with Contracts AI

Users can modify the default field descriptions by using the enhanced contracts digitization feature. Enhance the accuracy of field value extraction from a file based on predefined fields. Map and extract values for any field in the file by providing precise and clear descriptions for generative AI to extract values. Use Context Definitions to create extraction templates.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions. Einstein generative AI is available in Lightning Experience.

Who: To create extraction templates, users need the CLM Admin User and Context Service Admin permission sets.

Why: In previous releases, the extraction prompt, the extraction fields and their descriptions were predefined and couldn't be altered. Now, for extraction users can either customize the fields and their descriptions or can choose to use a new out-of-the-box ContractExtractionContext mapping. The mapping includes an attribute definition and context mapping for extracting data from predefined fields such as contract name, first party, third party, contract start date, and end date to facilitate contract record creation.
