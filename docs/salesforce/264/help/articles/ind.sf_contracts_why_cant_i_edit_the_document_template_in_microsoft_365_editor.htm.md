# Why Can’t I Edit the Document Template in Microsoft 365?

Document templates with tokens created in Microsoft Word can’t be edited directly in Microsoft 365 due to lack of feature parity.

Error

Unable to edit the document template with tokens in Microsoft 365.

Solution

Download the document template.
Open the file and save it under a different name.
Open the new file in Microsoft 365.
