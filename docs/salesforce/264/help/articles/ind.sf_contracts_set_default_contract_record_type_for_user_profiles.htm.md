# Set Default Contract Record Type for User Profiles

Set the default contract record type for your user profiles.

To set a default record type for a user profile.

From Setup, in the Quick Find box, enter Profiles and then select Profiles.
Click the profile for which you want to set the record type.
Scroll to Record Type Settings | Standard Record Type Settings.
Click Edit next to Contract.
In Selected Record Types, add the applicable record types from the Available Record Types list.
In Default Record Type, select the default record type for your user profile.
For example, Contract Lifecycle Management.
Save your changes.
