# Prepare for Microsoft 365 and Azure Integration Using Guided Setup

Before integrating Microsoft 365 and Azure with Salesforce, complete these prerequisites for a smooth setup process.

REQUIRED EDITIONS
REQUIRED
EDITIONS
Available in:	Lightning Experience
Available in:	Professional, Enterprise, Unlimited, and Developer Editions
USER PERMISSIONS NEEDED
To access the Microsoft 365 and Azure Integration Guided Setup:	CLM Admin User
Go to Guided Setup:
In Setup, find and select Microsoft 365 and Azure Integration.
Click Prerequisites.
Create a Microsoft Azure Account
Create a Microsoft Azure Account.
Click the highlighted card to open the Azure account creation page
Follow the on-screen instructions to create your Azure account.
Log in to Microsoft Azure.
Click Log in to Microsoft Azure.
Click the highlighted card to access the Microsoft Azure login page.
Enter you credentials to log in to your Azure account.
Assign Microsoft 365 Licenses to Users
Click Add a Microsoft 365 License.
Click the highlighted card to view the Assign licenses to users in Microsoft 365 documentation.
Follow the steps in the help guide to assign Microsoft 365 licenses to your users.
Add Permission Set Licenses for Salesforce Contracts
Click Permission Set Licenses.
Click the highlighted card to open the Salesforce Permission Set Licenses documentation.
Follow the instructions to assign the required Permission Set Licenses for Salesforce Contracts.
Complete prerequisites:
Select the checkbox and click Mark as Done.
