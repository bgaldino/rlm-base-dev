# Customize Prompt Templates for Contract Search

Tailor prompt templates to improve the accuracy and relevance of contract search results for your business needs. Using Prompt Builder, select standard templates such as Contract Q&A or Summarize Contract, save them as new versions, and then customize as needed.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Professional, Enterprise, Unlimited, and Developer editions with the Einstein for Sales, Einstein for Platform, or Einstein for Service add-on, Revenue Cloud Advanced, or Einstein for Industries (X).
USER PERMISSIONS NEEDED
To customize prompt templates:	Prompt Template Manager permission set
In Setup, find and select Prompt Builder.
Select a contract search related template to customize.
Contract Q&A
Summarize Contract
Make the required changes.
Click Save As and select Save as a New Version.
Save your changes and click Activate.
