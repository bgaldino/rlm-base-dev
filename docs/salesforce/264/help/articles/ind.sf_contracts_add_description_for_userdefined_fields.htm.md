# Add Description for User-Defined Fields

Add descriptions for user-defined extraction fields. Each description acts as a prompt for generative AI, so precise and clear descriptions improve extraction accuracy.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 
To add a description for user-defined fields:	Context Service Admin
NOTE To modify the prompt description for the seven predefined fields under the Document (Attribute) Fields tab, you must first add these fields as new attributes to your custom persistence mapping with a new name. After that, map those fields to the previously mapped contract fields. Then, add better prompt descriptions in the Additional Field Mapping tab.
From Setup, in the Quick Find box, enter Contract Lifecycle Management, and then select Contracts AI.
Open the extraction template that you want to modify.
Go to the Additional Field Mapping tab.
The user-defined fields show up under the Additional Field Mapping tab.
To modify or add a description, click  next to the custom field.
Make your edits.
Save your changes.
