# Delete an Obligation

Only the obligation manager assigned to an obligation can delete the obligation.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 


To delete an obligation:

	

Obligation Manager permission set

From the App Launcher, find and select Obligations.
Click the obligation that you want to delete.
Select Delete from the dropdown.
Click Delete.
