# Delete a Bulk Extraction Configuration

To delete a bulk extraction configuration, you must first delete all associated contract extraction results. Deleting a configuration doesn’t remove previously generated extraction results.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Professional, Enterprise, Unlimited, and Developer Editions
USER PERMISSIONS NEEDED
To delete a bulk extraction configuration:	CLM Admin User
From Setup, in the Quick Find box, enter Contracts AI, and then select Contract Extraction.
In the Bulk Extraction Configuration table, find the configuration that you want to delete.
Click Delete.
