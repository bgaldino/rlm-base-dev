# Contract Review in Microsoft 365

Salesforce facilitates a seamless internal collaboration and external review process for contract management.

USER PERMISSIONS NEEDED	 
To add the add-in to your Microsoft 365 Word:	Microsoft365WordUser
REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions

Contracts require negotiation for which you can collaborate on individual contract documents. A well-coordinated and synchronized parallel review process can significantly reduce errors, cycle time, and loss of intermediate information. Salesforce Contracts tracks and shows the changes by using redlines and including the details about who made the change and when.

NOTE To maintain the integrity of the contract authoring and review flow, users should avoid manually changing the document mode (status) in Microsoft Word (such as switching from Editing to Reviewing). The system handles the mode changes in the backend, manual updates can break the contract review workflow. In the Microsoft 365 Add-in, the document status cannot be changed manually, this restriction ensures the process remains consistent.

Before you send a contract document for review, generate a contract document in Microsoft Word.
