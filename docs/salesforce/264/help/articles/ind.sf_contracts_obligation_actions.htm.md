# Obligation Actions

The permissible actions for an obligation depend on the persona. You can use the obligation actions on the Obligations tab on a contract record page.

ACTION	DESCRIPTION
Edit	Update obligation details such as name, reference object, assignee, party, and status.
Delete	Delete an obligation.
Clone	Clone any obligation to create an obligation. The name of the cloned obligation must be unique.
Change Owner	Assign the obligation to another user. See Change Obligation Owner.
Add Task	Create and associate Salesforce tasks for upcoming obligations within contracts. See Create a Salesforce Task for an Obligation.
