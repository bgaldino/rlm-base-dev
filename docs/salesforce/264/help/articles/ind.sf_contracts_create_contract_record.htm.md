# Create Contract Record

After you review the extracted contract details and clauses, create a Salesforce contract record with the extracted contract details. Contract creation deletes the extraction record from the Contract Extraction Results, and the contract data is mapped to the contract fields in Salesforce.

Make sure the contract details have been extracted using the Contracts AI.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 
To extract contract and clause details from PDFs	

Contracts AI User

AND

Prompt Template User

AND

NLP Service

AND

Scoring Framework Admin

Go to the extracted contract fields page.
Verify that the source file used for contract extraction is uploaded. If it isn't, upload it.
Make sure all the required contract fields are populated.
Click New Contract Record.
Click Create.
To view the document used for extraction, click View Contract Document.
