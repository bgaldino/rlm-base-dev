# Create Other Versions of Salesforce Contracts Analytics

After the initial instance of Salesforce Contracts Analytics is auto-created, you can create other versions via Analytics Studio so that your team members can use the version that meets their needs. You can create as many versions as you need.

NOTE While you can create as many Salesforce Contracts Analytics versions as you like, recipe and data sync limits apply.

To create other versions of Salesforce Contracts Analytics:

From Setup, in the Quick Find box, enter Salesforce Contracts Analytics, and then select Salesforce Contracts Analytics Setup.
From Salesforce Contracts Analytics Setup, you can see details about your auto-installed app and a link to Analytics Studio. To create more versions of Salesforce Contracts Analytics, click the link to Analytics Studio
In Analytics Studio, click Create.
To open the template selector, select App, then select Create App from Template.
Locate the Salesforce Contracts Analytics tile, select it, and click Continue.
Review the app preview page, and click Continue to open the configuration flow.
Select Create a brand new app and click Continue. The app runs a compatibility check against your org to ensure it includes the data to successfully create the app’s datasets, recipes, and dashboards. If it doesn’t, follow the instructions in the error message to add the required data and start the app creation process again.
When the org compatibility check succeeds, click Looks good, next.
Name your app, and click Create.
