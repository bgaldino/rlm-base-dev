# Why Can't I Add a Line in a Section in a Microsoft 365 Document?

When you create a new line Microsoft 365 Word by using Shift+Enter, the result is an uneditable line.

Error

Unable to add a new line inside a section in a Microsoft 365 Word document.

Solution

Create a Section in Document Template
Select Shift + Enter twice.
This creates two lines below.
Use the Up arrow key to move your cursor to the first line.
Enter your content.
