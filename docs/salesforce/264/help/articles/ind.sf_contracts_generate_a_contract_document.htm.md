# Generate Contract Document Versions

Generate Contract Document Versions

When you create a new contract or modify an existing contract, you can create a new document by selecting a document template or by importing a pre existing document or by creating a document in Microsoft 365.

Generate a Salesforce Contract Document

You can select a document template and generate a contract.

When you select a template and click Generate Document action button, a document is generated using the template conditions, mappings, and so on. A new version of the contract document is generated. The contract document view is read-only. You can select the format to view or download the contract - Microsoft Word or PDF. Typically, you want to save a contract as a Microsoft Word document so others can edit it, if necessary. After all the parties agree on the contract, you can import the contract document as a Word or PDF file.

On the Contract record details page, from Select template, select a template to generate the document.
Click Generate Document.
Import a Contract Document

You can import a pre existing contract document to generate a new contract document version.

You can import multiple files. The contract document view is read-only. The preview functionality is available for both .docx and .pdf file formats.

On the Contract record details page, select Import Contract to upload an existing document. You can upload a .pdf and/or .docx file.
Select Upload Files. After uploading the file, select Done.
Select Import.
Create Contract in Microsoft 365 Editor

You can generate a contract document using the Microsoft 365 editor.

From the contract document page, select Create Contract in Microsoft 365 to generate a document using Microsoft 365 editor.
Click Next. A new contract document opens on a new tab in Microsoft 365 editor.
