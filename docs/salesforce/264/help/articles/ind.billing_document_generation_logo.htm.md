# Customise Invoice PDF Template with Your Company Logo

Add your company logo to invoice PDF documents by uploading the logo file to your Salesforce org. Generated invoice PDFs show the logo at the top of the document.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Developer Editions with the Revenue Cloud Billing license. Contact your Salesforce account executive for more information.
USER PERMISSIONS NEEDED
To add your company logo to invoice PDF documents:	DocGen Designer permission set

If you haven't installed Document Generation 2.0 in your Salesforce org, install Omnistudio to use the logo capabilities.

Document Generation 2.0 supports dynamic image tags, which are used to add the company logo on PDF documents.

From the App launcher, find and select Files.
Upload the logo.

Make sure your logo file is in PNG format and follows this file naming convention: Company_Logo.

NOTE Only one logo can be uploaded as a File records. To change the logo, delete the existing logo and add a new logo.

When you generate invoice PDF documents, you see the logo at the top of the PDF document.
