# Contract Authoring in Microsoft 365 Editor

You can add clauses from a clause library to simplify the contract authoring and editing process by making it easier to locate and add relevant clauses and to update the existing clauses.

Search for and add clauses while creating and editing documents.

View all the clauses within the document in the right pane.

Navigate between multiple references of the same clause.

Insert main or alternate clauses by searching for specific clauses.

Replace and delete clauses to modify the contract document.

Search for Standard Clauses in Clause Library
The Salesforce Contracts for Word add-in enables you to search for clauses and clause sets in Clause Library while editing contract documents in the Microsoft 365. The search results show only the active clauses or clause sets based on the search query.
Section Management in Salesforce Contracts
Section management is a crucial aspect of contract document designing, generation, negotiation, and execution. It effectively organizes and controls the content, leading to improved clarity, enforceability, and efficiency of the contract process.
Mark as Clause
Contract authors can mark any modified clause or content within a contract document as a clause.
Contract Review in Microsoft 365
Salesforce facilitates a seamless internal collaboration and external review process for contract management.
View Associated Clauses
After you check in a document created in the Microsoft 365 editor, you can access the associated clauses. View all clauses associated with the contract version from the Associated Clauses section. The Associated Clauses window includes the clause source (Marked Clause, Contracts AI, and Clause Library), the review status for each clause, and so on.
