# Agent Templates in Revenue Cloud

Quickly deploy AI-powered agents for your product-to-cash operations using Revenue Management agent templates. All Agentforce templates and topics within Revenue Cloud are Agentforce Employee Agent (AEA) templates. You must have access to the Revenue solutions to use them.

Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Developer Editions of Revenue Cloud with the Revenue Cloud Advanced license with the Agentforce Employee Agent add-on.
