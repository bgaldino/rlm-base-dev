# Workflow to Configure New Contract Status Values and Map To Contract Object State Definition

You can configure a customized Object State Definition for your users by adding new contract status values and mapping it to an existing contract Object State Definition.

Here’s the sequence of steps that you need to follow:

Create New Contract Status Value

Define New Contract Object State Value

Map New Contract Status Value to a New Contract Object State Transition

Create New Contract Status Values
You can create new contract status values from Setup and reorder the sequence of the contract statuses
Define New Contract Object State Values
From the Object State Definition, you can update your contract object state definition.
Map New Contract Status Value to a New Contract Object State Transition
You must associate the new contract status value to the new contract object state transition using the contract object state definition so that the new status values reflect in the contract states bar.
