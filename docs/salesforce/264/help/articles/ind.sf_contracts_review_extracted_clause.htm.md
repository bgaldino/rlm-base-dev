# Review Extracted Clause

Clause designers can directly review the extracted clause content and mark it as reviewed without any modifications. You can edit or delete the extracted clause using the action dropdown next to the clause.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 
To extract contract and clause details from PDFs	

Contracts AI User

AND

Prompt Template User

AND

NLP Service

AND

Scoring Framework Admin

Open the Extracted Contract Clauses tab.
Click to preview the clause content.
If you’re satisfied with the extracted clause content and don’t want to make changes, click the pencil icon, and select Review Status.
The clause review status gets updated.
