# Create a Salesforce Task for an Obligation

The obligation manager can easily create and associate Salesforce tasks for upcoming obligations within contracts, to track and meet obligations within defined time frames. They can then assign these specific tasks to an obligation assignee. The tasks can be recurring tasks, reminders, or one-time tasks.

USER PERMISSIONS NEEDED	 


To create and assign an obligation task:

	

Obligation Manager permission set

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions

The manager can associate multiple tasks with an obligation. The manager can view the associated tasks in the Activity section on the obligations record.

Enable recurring tasks.
See Enable Recurring Tasks in Lightning Experience and the Salesforce Mobile App.
Customize notifications for task assignments.
See Enable Task Notifications in Lightning Experience.
From the App Launcher, find and select Obligations.
Click the obligation that you want to create a task for.
Select Add Task from the dropdown.
Enter the task details.
Save your changes.
