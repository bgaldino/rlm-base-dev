# Edit a Draft Clause

Clause designers can edit the draft clause and then add the clause directly to the clause library. You can also delete the draft clause if they don’t want to add the clause to the clause library.

You can edit a clause from Contracts AI UI or from the Document Clause Sets and substitute the specific clause content.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 
To create and edit document clauses:	Clause Designer User
Open the clause in Contracts AI.
Click Edit.
Edit clause details.
Name: Enter a name for the clause.
Format: Use the Rich Text or Non Formatted option to edit the clause content.
Content: Edit the clause details.
Save your changes.
