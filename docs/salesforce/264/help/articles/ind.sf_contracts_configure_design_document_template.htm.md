# Design and Configure Document Templates for Salesforce Contracts

Document templates define the structure, layout, and dynamic content of the contract documents that Salesforce Contracts generates.

Salesforce Contracts supports two approaches to document template design. The approach you use depends on your licensing and document generation requirements.

Salesforce Contracts document templates
Design DOCX and Microsoft 365 Word templates directly in Salesforce. Use Context Service to map Salesforce data to template tokens for dynamic document generation. You can export templates from one org and import them into another for deployment across environments. See Document Management in Salesforce.
Omnistudio Document Generation templates
Design Microsoft Word and Microsoft PowerPoint templates using the Omnistudio Document Generation framework. This approach requires the Omnistudio license and supports both client-side and server-side document generation, custom classes, and dynamic content such as hyperlinks, rich text, and images. See Omnistudio Document Generation Document Templates.
