# Enable Private Online External Review

If customers use the guided setup for Microsoft 365 and Azure Integration, the admin has to enable the external private review in the Set Up the Auth Provider section. Contract authors can then start private online external reviews.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Performance editions.
USER PERMISSIONS NEEDED
To enable external private review in the guided setup configuration	CLM Admin User

Make sure you have completed the Microsoft 365 and Azure Integration guided setup.

In Setup, find and select Microsoft 365 and Azure Integration.
Access the Auth Provider Setup by expanding Set Up the Auth Provider.
Click New Auth Provider.
Complete the steps mentioned in Configure an Auth Provider.
Select Enable Private Mode Review.
