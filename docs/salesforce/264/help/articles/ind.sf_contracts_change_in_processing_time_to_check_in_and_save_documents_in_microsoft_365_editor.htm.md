# Change in Processing Time to Check In and Save Documents in Microsoft 365 Editor

Now, it takes up to one minute to check in a contract document version and save a document template in the Microsoft 365 editor. The processing time depends on the document’s size and contents. Wait until the processing is complete because closing the document ends the check in and saving process.

To prevent data discrepancies between the Microsoft 365 editor and Salesforce, press Command+S or Ctrl+S before you click Save or Check In. After making changes to the document, use this keyboard shortcut to ensure that content in the editor and Salesforce are synced.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

When: Salesforce Contracts enforces this update in Winter '24.
