# Add Non-Standard Clauses to the Clause Library To Ensure Reusability

Clause users can use the intensive review process to submit non-standard clauses, such as clauses drafted by Contracts AI or marked as clauses for the designer's review. Once clauses are added to the library, contract users can then reuse them anytime, across various contract documents and templates.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

Who: To review clauses, users need the Clause Designer User permission set.

How: Clause designers can use a dedicated dashboard to view requests, receive notifications, and delete clause requests. They can also review and make modifications to the clause, clause set name, and clause description before they accept the clause library addition request. Clause users can raise the review request directly from the Microsoft 365 editor, contract record page, or extraction results page. Users can easily submit a request for clause review, and associate clauses with existing clause sets or to add them to a new clause set. Users can also set the clause language.
