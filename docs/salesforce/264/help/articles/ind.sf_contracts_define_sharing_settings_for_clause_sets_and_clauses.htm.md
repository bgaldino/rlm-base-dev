# Define Sharing Settings for Clause Sets and Clauses

Configure sharing settings to control user access to document clauses and clause sets at the object, field, and record levels.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 
To configure clause category:	ClauseDesignerUser
From Setup, in the Quick Find box, enter sharing and select Share Settings.
Update Share Settings for Document Clause:
In Manage Sharing Settings for, select Document Clauses.
In the Document Clause Sharing Rules section, click New.
Create sharing rules based on a sharing rule type: Owner-Based, Criteria-Based, or Guest User.
See ​Create Sharing Rules​.
Save your changes.
Update Share Settings for Document Clause Sets:
In Manage Sharing Settings for, select Document Clause Sets.
In the Document Clause Set Sharing Rules section, click New.
Create sharing rules based on a sharing rule type: Owner-Based, Criteria-Based, or Guest User​.
​See ​​Create Sharing Rules​​.​​
