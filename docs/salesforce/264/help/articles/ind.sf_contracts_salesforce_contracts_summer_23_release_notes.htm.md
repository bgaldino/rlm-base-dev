# Salesforce Contracts Summer '23 Release Notes

In Summer '23, Salesforce Contracts introduces a central repository for pre-approved clauses as well as enhanced parent and child mappings to create and update contracts. View and manage contracts in a console app. Use console-based dashboards and embedded analytics to analyze the performance of your contract management process. Edit and manage documents with a Microsoft 365 add-in app.

Design Templates and Create and Edit Contract Documents with Microsoft 365 Word Features
The Salesforce Contracts Connector for Word add-in integrates Microsoft 365 Word with Salesforce Contracts. Design and maintain document templates, create and edit contract documents, and insert content such as clauses from the Clause Library directly in the Microsoft 365 editor.
Create and Maintain Document Clauses in a Centralized Library
The Document Clause Library is a central repository of pre-approved and pre-built standardized legal content. Use approved clauses to create document templates and generate legal documents such as contracts. By using the Clause Library, the sales team can create contracts without involving the legal team at every step. The library consolidates and stores all legal language in one place, speeding up the document creation process.
Create and Update Contracts with Enhanced Parent and Child Mappings
Salesforce Contracts uses field mappings to create and update contracts from standard or custom objects. In addition to parent-to-parent and child-to-child mappings, Salesforce Contracts supports parent-to-child and support-based mapping methods for greater flexibility.
Quickly Create, and Manage Contracts from Salesforce Contracts Console App
The Salesforce Contracts Console serves as a one-stop solution for contract management. It includes contracts, document clauses, and document clause sets in one app for easy access to all relevant Salesforce Contracts features. Users can choose between the standard contract record page or the new contract record page available in the Salesforce Contracts console app. The console provides a streamlined and intuitive user experience.
Track and Manage Your Contracts Better
Get a highly accurate overview and analysis of your contracts and their lifecycle-related data by using the console-based dashboards and embedded analytics of Salesforce Contracts Analytics. Use these data-driven insights to analyze the performance of your contract management process based on completion time and revenue. Evaluate the contracts in various stages, prioritize renewals, compare product pricing across the organization, and identify and fix the contracts that need attention.
