# Turn On Context Service for Extracting Contract Details in Salesforce Contracts

Grant users access to use context service to extract contract details from files. By default, the Context Service for Salesforce Contracts option is disabled.

Turn on the Context Service setting.

Turn on the Salesforce Contracts setting.

The Salesforce org must have the Salesforce Contracts permission set license. It includes the Context Service user permissions.

Complete Contracts AI setup requirements.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 
To turn on Context Service for Salesforce Contracts:	CLM Admin User
From Setup, in the Quick Find box, enter Contract Lifecycle Management, and then select General Settings.
Turn on Context Service for Salesforce Contracts.
This action loads the default context definition, ContractsExtractionContext for Salesforce Contracts, under the Context Definitions. As a result, the Context Use Case Mapping setup page becomes available under Contract Lifecycle Management. The use case mapping Extract Contract Details with preconfigured corresponding mapping also becomes available.
