# Submit a Contract for Approval by Using Advanced Approvals for Salesforce Contracts

Generate a contract document, submit it for approval, and manage the approval request.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Professional, Enterprise, Unlimited, and Developer Editions
USER PERMISSIONS NEEDED
To submit a contract for approval by using the advanced approval process:	

CLM Admin

AND

DocGen User

Before you begin:

Make sure that the contract type is configured with an advanced approval flow.
Make sure that you have permission to submit contracts for approval.
Generate and check in the contract document.
Open the contract record.
Click Create Contract.
Select a template and generate the contract document.
Wait for document generation to complete.
Check in the document.
Submit the contract for approval.
Review the contract document.
Click Submit for Approval.
Submitting the contract updates the contract status to In Approval and invokes the approval flow when it’s mapped through Contract Type Config.
Monitor approval progress.
Open the contract record.
Click the Advanced Approvals tab.
View assigned approvers and approval status.
Approval assignments reflect the conditions and logic defined in the approval flow. You can track progress from the contract record and act if updates are required.
If needed, recall the approval request.
Open the approval record from the Advanced Approvals tab.
Click Recall.
Recall ends the approval process. Configure the approval flow to update the contract status and return the contract to an editable state, such as Draft.
