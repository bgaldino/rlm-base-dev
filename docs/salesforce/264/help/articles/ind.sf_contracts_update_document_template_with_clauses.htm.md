# Modify the Clauses in Document Templates

Modify document templates by adding, removing, and updating clauses.

Select Create New Version to create another version of the active template.

Select Open in Microsoft 365 to open the new template document version in Microsoft 365 editor.

When the document is open, you can update, delete, or replace clauses. Select the Salesforce Contracts for Word add-in from the Home tab. The Edit, Replace, and Delete options are available in the add-in pane for a clause.

Replace: Select Replace from the dropdown menu next to the clause that you want to replace. Search for and select the desired clause or clause set in the clause library, and click Replace Clause. The add-in pane replaces the existing clause with the selected clause and updates the clause details accordingly.

Delete: Select Delete from the dropdown menu next to the clause that you want to remove from the document.

Edit: Select Edit from the dropdown menu next to the clause that you want to update and make the changes. A modified clause is no longer regarded as a document clause and is converted to plain text, unless you made only formatting changes. The clause reference is also removed from the add-in pane. Select Refresh to view the updated data in the panel.

Add: To add a clause, select Clause from the Insert New dropdown.

Alternatively, use clause tokens to modify referencing clauses in your template. For example, when designing, edit a clause token directly in the document template by copying it from the respective document clause. Salesforce resolves the change the next time the document is generated.

After updating the clauses and content, save your changes. This uploads the updated document to the template designer.
