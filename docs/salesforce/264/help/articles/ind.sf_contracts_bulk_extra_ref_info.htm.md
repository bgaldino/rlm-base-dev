# Considerations for Bulk Extraction

Understand the limits, permissions, and supported configurations for bulk extraction.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Professional, Enterprise, Unlimited, and Developer Editions
Bulk Extraction Limits

If a document exceeds these limits, the system skips the document and continues processing the remaining files.

ITEM	LIMIT
Maximum file size	20 MB
Maximum pages per document	100
Supported file types	PDF
Maximum fields per template	50
Supported External Repositories
Amazon S3
Google Cloud Storage
SharePoint
Google Drive
Azure Blob Storage
