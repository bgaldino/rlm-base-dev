# Licenses and Permissions for Salesforce Contracts Analytics

The Salesforce Contracts Analytics setup page is available only for Salesforce admins, Salesforce Contracts admins, and Salesforce Contracts Analytics admins.

REQUIRED EDITIONS AND USER PERMISSIONS


Available in: Lightning Experience
Available with Salesforce Contracts for an additional cost in: Enterprise, Unlimited, Professional, and Developer editions
USER PERMISSIONS NEEDED	 
To set up Salesforce Contracts Analytics:	

CRM Analytics Plus Admin

AND

Salesforce Contracts Analytics Admin


To assign permission sets:	Assign Permission Sets
To view, create, edit, and delete the Salesforce Contracts Analytics dashboard:	

Salesforce Contracts Analytics Admin

AND

CRM Analytics Plus Admin


To view the Salesforce Contracts Analytics dashboard:	

Salesforce Contracts Analytics User

AND

CRM Analytics Plus User

LICENSES NEEDED	 
CRM Analytics	

EinsteinAnalyticsPlus platform license

EinsteinAnalyticsPlus AddOn license


Salesforce Contracts Analytics	

InsightsClmAnalytics platform license

Salesforce Contracts Analytics App user license
