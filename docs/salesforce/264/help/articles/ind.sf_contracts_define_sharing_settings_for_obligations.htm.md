# Define Sharing Settings for Obligations

To make the obligation records created by your obligation manager accessible to all users within an org, system admins must define the sharing settings.

The CLM admin can control data access at multiple levels. For example, you can control the access that your users have to objects with object permissions. Within objects, you can control user access to fields by using field-level security. To control access to data at the record level, use sharing settings and restriction rules.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
USER PERMISSIONS NEEDED	 


To define sharing settings for obligations:

	

CLM Admin User

From Setup, in the Quick Find box, enter sharing, and click Sharing Settings.
Click Edit.
Provide access to your obligations:
The default internal access is set to Public Read Only, and external access is set to Private. You can define your own sharing settings.

Default internal access: Public Read Only

Default External Access (If needed): Private

Save your changes.
