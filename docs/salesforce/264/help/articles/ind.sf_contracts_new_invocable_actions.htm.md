# New Invocable Actions in Salesforce Contracts

Use the ten new invocable actions in Salesforce Flows to perform actions such as the creation of document versions, contract creation and updates, dynamic contract actions, and e-signature functionalities to manage contract lifecycle.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, Professional, and Developer editions.

Who: To use invocable actions, users need the CLM Runtime User or CLM Admin permission set.

How: On the Flow Builder canvas, click Add Element, and select Action. Select the action that you want to use.
