# Org Settings and Object Requirements for Salesforce Contracts Analytics

Salesforce Contracts Analytics requires specific org settings and objects so that dashboards are populated correctly.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
NOTE The Analytics Apps and Template functionality included as a part of CRM Analytics is available in English only.

Salesforce org requirements for using Salesforce Contracts Analytics.

Salesforce Contracts Analytics uses recipes to power dashboards. Recipes require that your org is configured for data sync or direct data.

Your org needs at least one record of each of these objects:

Account

Quote

Product

Contracts

Sales Contract Lines

Contract Document Version

Document Template

After you install Salesforce Contracts Analytics, complete the post-installation steps of scheduling a data sync and scheduling the recipes.
