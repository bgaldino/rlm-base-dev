# Create Templates by Using Microsoft 365 Word in Document Template Designer

Document template designers can use the rich capabilities of the Microsoft 365 to create document templates.

Use Microsoft 365 Word to create documents online that contain formatted text, including tables of contents, tables, paragraphs, columns, and images.

USER PERMISSIONS NEEDED	 
To add the add-in to your Microsoft 365 Word:	Microsoft365WordUser
REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, Professional, and Developer Editions
From the App Launcher, find and select Document Template Designer.
Click New.
Enter a name for the template.
From Template Type, select Microsoft 365 Word.
To determine how the template's tokens are populated, select a Token Mapping Method.

OmniDataTransform: Enter a Mapping Data Mapper Bundle name to transform data and a Data Extract Data Mapper Bundle Name to retrieve Salesforce data. See Omnistudio Data Mappers.

Custom Class: Enter a Custom Class name. See Using a Custom Class in a Generation Document Template for Omnistudio Document Generation.

Select the usage type.
Select the document generation mechanism.
See Client-Side and Server-Side Document Generation Compared.
Save the template details.
To create the document template by using the editor, click Open in Microsoft 365.
Update the blank document, and save your changes.
This uploads the document to the template designer. See Create a Document Template by Using Clauses .
Create a Document Template by Using Clauses
From the clause library, add preapproved clauses to the document template.
Modify the Clauses in Document Templates
Modify document templates by adding, removing, and updating clauses.
