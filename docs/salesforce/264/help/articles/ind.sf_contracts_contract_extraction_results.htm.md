# Contract Extraction Results

The status of the contract extraction is restricted to five statutes.

STATUS	SUPPORTED ACTIONS
Extraction in Progress	Wait for the status to change to Review Not Started to review the extracted content. You can only delete the extracted file when the extraction is in progress.
Review Not Started	

Initiate the review of the extracted contract fields and clauses.

The status changes to Review in Progress when you click Save on the Extracted Contract Fields tab or make changes to an extracted clause in the Extract Contract Clauses tab.


Review in Progress	Continue the review of the extracted contract fields and clauses.
Review Completed	Add the extracted clause to the clause library, if necessary.
Extraction Failed	Delete the extraction record and reinitiate the PDF extraction.
