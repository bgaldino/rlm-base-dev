# Salesforce Contracts Release Notes

Salesforce Contracts application allows customers to manage the complete end-to-end lifecycle of contracts. Contracts can be associated with opportunities, orders, quotes, standard Salesforce objects, and custom objects.

Review the new and enhanced features for Salesforce Contracts.

Salesforce Contracts Release Notes Winter '25 and Later
The Salesforce Contracts release notes are now part of the Salesforce Revenue Management Release Notes section.
Salesforce Contracts Summer '24 Release Notes
Added functionality for Customer Community Plus users, DocGen Designers, Contract authors, and Contract Administrators.
Salesforce Contracts Spring '24 Release Notes
Use Contracts AI in Salesforce Contracts to create clauses and digitize legacy contracts by using generative AI. Contract authors can now facilitate collaborative external contract reviews. Document template designers can use the new document template designer to create templates. Also, use the several new organizational preference settings to better manage the Salesforce Contracts features.
Salesforce Contracts Winter '24 Release Notes
Salesforce Contracts has introduced obligation and section management. Contract authors can now facilitate collaborative internal contract reviews, and offline external contract reviews. Additionally, your users can attach additional files for contract e-signature and mark content within a document as clauses.
Salesforce Contracts Summer '23 Release Notes
In Summer '23, Salesforce Contracts introduces a central repository for pre-approved clauses as well as enhanced parent and child mappings to create and update contracts. View and manage contracts in a console app. Use console-based dashboards and embedded analytics to analyze the performance of your contract management process. Edit and manage documents with a Microsoft 365 add-in app.
Salesforce Contracts Spring '23 Release Notes
For Spring '23, Salesforce Contracts has introduced custom contract actions, and throttling to maintain the consistency and resilience of Omnistudio server-side document generation service. Salesforce Contracts now supports digital experience partner users.

This section provides a summary of the new Salesforce Contracts application in Winter '23.
