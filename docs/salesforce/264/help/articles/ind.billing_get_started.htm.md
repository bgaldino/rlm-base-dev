# Get Started with Billing

Turn on Billing to efficiently set up, manage, and run billing for your sales models. Tailor the experience of using Billing for all users using permission sets to give them precise access to what they need.

Billing in Revenue Cloud
Billing takes billing schedules through invoicing, payment, and accounting. Billing creates those schedules when you activate an order in Revenue Cloud, or when you use the Create Standalone Billing Schedules API.
Turn On Billing in Revenue Cloud
Enable Billing to start using Billing features.
Assign Permissions to Access Billing Features
Assign your users the required permission sets based on their persona, and for the APIs for which they need access.
Guided Setup for Billing
Admins can use the Billing Guided Setup for a ‌step-by-step guidance to complete key tasks that are required to set up Billing.
