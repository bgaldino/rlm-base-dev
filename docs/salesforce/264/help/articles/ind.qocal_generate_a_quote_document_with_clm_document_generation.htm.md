# Generate a Quote Document with CLM Document Generation

Generate a large-scale PDF document from a quote. Select a document template, preview the generated PDF, and access the saved document from the quote.

REQUIRED EDITIONS
Available in: Lightning Experience
Available in: Enterprise, Unlimited, and Developer Editions of Revenue Cloud where Transaction Management is enabled

Before you generate a quote document, set up CLM Document Generation for quotes.

On the quote record page, select Generate Document.
In the Generate Quote Document window, select a document template.
Select Generate.

Salesforce saves the PDF to the quote. Track the save progress on the Related tab. After Salesforce links the PDF to the quote, the document appears in the Quote PDFs related list. Select the PDF name to open PDF Preview.
