# Clause Category Response

Output representation of the field-level details for a clause category.

| Property Name | Type | Description | Filter Group and Version | Available Version |
| --- | --- | --- | --- | --- |
| `id` | String | The ID of the custom clause configuration. | Small, 57.0 | 57.0 |
| `name` | String | The name of the clause configuration. | Small, 57.0 | 57.0 |
| `usageType` | String | The usage type for the clause configuration. Possible values are `Contract Clause Category` or `Disclosure Category`. | Small, 57.0 | 57.0 |
