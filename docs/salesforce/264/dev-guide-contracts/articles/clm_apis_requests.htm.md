# Request Bodies

Here’s a list of Salesforce Contracts API request bodies.

- 
**[Content Link Input](./connect_requests_content_link_input.htm.md)**  

Input representation of the request to fetch the content token data from the ContentLink     object.

- 
**[Content Link Data Sync Input](./connect_requests_content_link_data_sync_input.htm.md)**  

Input representation of the entire request to synchronize token data from a document to     sObjects.

- 
**[Content Link Details Input](./connect_requests_content_link_details_input.htm.md)**  

Input representation of the request to synchronize content token data from a document to     sObjects. It specifies the ID of an individual content link and its corresponding new value to     be updated.

- 
**[Contract Action Input](./connect_requests_contract_action_input.htm.md)**  

Input to get action details for the contract.

- 
**[Contract Input](./connect_requests_contract_input.htm.md)**  

Input to create and update contract.

- 
**[Contract Risk Analysis Input](./connect_requests_contract_risk_analysis_input.htm.md)**  

Input representation to start a risk analysis for a contract       document version.

- 
**[Document Template Request](./connect_requests_document_template_request.htm.md)**  

Input representation of a document template resource.

- 
**[Document Template Update Input](./connect_requests_document_template_update_input.htm.md)**  

Input representation to update a document template.

- 
**[Envelope Documents Input](./connect_requests_envelope_send_documents_reques.htm.md)**  

Input to get document details for e-signature.

- 
**[Envelope Email Notification Input](./connect_requests_envelope_send_email_notification_reques.htm.md)**  

Input to get email notification details.

- 
**[Envelope Email Settings Input](./connect_requests_envelope_send_email_settings_reques.htm.md)**  

Email settings input to get email details from API.

- 
**[Envelope Notification Expiration Input](./connect_requests_envelope_send_notification_expirations_reques.htm.md)**  

Input to get notification expiration information.

- 
**[Envelope Notification Reminder Input](./connect_requests_envelope_send_notification_reminders_reques.htm.md)**  

Input to get notification reminder information for e-signature       document.

- 
**[Envelope Notification Input](./connect_requests_envelope_send_notification_reques.htm.md)**  

Input to get notification information for     e-signature.

- 
**[Envelope Recipient Details Input](./connect_requests_envelope_send_recipient_detail_reques.htm.md)**  

Input to get recipient details.

- 
**[Envelope Recipients Input](./connect_requests_envelope_send_recipients_reques.htm.md)**  

Input to get different recipients list.

- 
**[Envelope Send Input](./connect_requests_envelope_send_reques.htm.md)**  

Input request to send e-signature details from API.

- 
**[Envelope Void Input](./connect_requests_envelope_void_reques.htm.md)**  

Input to get void envelope related details.

- 
**[External Document Creation Input](./connect_requests_external_doc_creation_input.htm.md)**  

Input representation of the request to create an external       document.

- 
**[External Document Metadata](./connect_requests_external_document_metadata.htm.md)**  

Input representation of external document metadata.

- 
**[Extraction Context Attribute Mapping Input](./connect_requests_extraction_context_attribute_mapping_input.htm.md)**  

Input representation of attribute mappings used in the extraction context.

- 
**[Extraction Context Mapping Input](./connect_requests_extraction_context_mapping_input.htm.md)**  

Input representation of a extraction context mapping.

- 
**[Extraction Context Use Case Mapping Input](./connect_requests_extraction_context_use_case_mapping_input.htm.md)**  

Input representation of the use case-mapping configuration in the extraction     context.

- 
**[Object Reference Input](./connect_requests_object_reference.htm.md)**  

Input representation of object reference.

- 
**[Playbook Version Input](./connect_requests_playbook_version_input.htm.md)**  

Input representation for creating a playbook version.

- 
**[Section Input](./connect_requests_section.htm.md)**  

Input representation of a section.

- 
**[Save External Document Input](./connect_requests_save_external_document_input.htm.md)**  

Input representation to save external document to     salesforce.

- 
**[Template Input](./connect_requests_template_input.htm.md)**  

Input representation to get contract document related details.

- 
**[Usages Input](./connect_requests_usages.htm.md)**  

Input representation of usages.
