# External Document Resources

Manage Salesforce Contracts external documents. Users can save external documents. Get
information about external document details and update.

Available resources are:

| Resource | Description |
| --- | --- |
| [`/connect/external-document/save`](./connect_resources_external_document_save.htm.md "Save external documents.") | Save external documents. |
| [`/connect/external-document`](./connect_resources_external_document.htm.md "Get information about external document details and update.") | Get information about external document details and update. |

- **[External Documents Save](./connect_resources_external_document_save.htm.md)**  
  Save external documents.
- **[External Documents (GET, POST)](./connect_resources_external_document.htm.md)**  
  Get information about external document details and update.
- **[External Document Review (GET)](./connect_resources_external_document_review.htm.md)**  
  Retrieve external document for review using latest contract document version.
