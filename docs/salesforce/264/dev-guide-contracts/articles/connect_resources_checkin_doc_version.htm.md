# Check In Contract Document Version

Check in a contract document version using contract document version
      ID.

    

## Resource

      
      

```
/connect/clm/contract-document-version/$CONTRACT_DOCUMENT_VERSION_ID/checkIn
```

    

    

## Available Version

      
      

56.0

    

    

## HTTP Methods

      
      

PATCH

    

    

## Example for PATCH

      
      

```
https://YOUR_INSTANCE.salesforce.com/services/data/v56.0/connect/clm/contract-document-version/${contractDocumentVersionId}/checkIn
```
