# E-signature Resources

Manage Salesforce Contracts e-signature process. Users can view list of documents sent
for e-signature and recipients. Update e-signature envelope status, notification settings and
get e-signature signer roles.

Available resources are:

| Resource | Description |
| --- | --- |
| [`/connect/e-sign/signature-requests/$SOURCE_OBJECT_ID/​envelope/send`](./connect_resources_esign_envelope.htm.md "Send document envelope to vendor for e-signature.") | Send document envelope to vendor for e-signature. |
| [`/connect/e-sign/documents`](./connect_resources_esign_documents_list.htm.md "View a list of documents sent for e-signature.") | View a list of documents sent for e-signature. |
| [`/connect/e-sign/signature-requests/$SOURCE_OBJECT_ID/​envelopes/status`](./connect_resources_esign_envelope_status.htm.md "Update e-signature envelope status.") | Update e-signature envelope status. |
| [`/connect/e-sign/signature-requests/$SOURCE_OBJECT_ID/​envelopes/void`](./connect_resources_esign_envelope_void.htm.md "Expire or void envelopes associated with an object.") | Expire or void envelopes associated with an object. |
| [`/connect/e-sign/recipients`](./connect_resources_esign_recipients.htm.md "Get list of e-signature recipients.") | Get list of e-signature recipients. |
| [`/connect/e-sign/notification-settings`](./connect_resources_esign_notification_settings.htm.md "Get e-signature notification settings.") | Get e-signature notification settings. |
| [`/connect/e-sign/signer-roles`](./connect_resources_esign_signer_roles.htm.md "Get e-signature signer roles.") | Get e-signature signer roles. |

- **[E-signature Document List](./connect_resources_esign_documents_list.htm.md)**  
  View a list of documents sent for e-signature.
- **[E-signature Envelope](./connect_resources_esign_envelope.htm.md)**  
  Send document envelope to vendor for e-signature.
- **[E-signature Envelope Status](./connect_resources_esign_envelope_status.htm.md)**  
  Update e-signature envelope status.
- **[E-signature Envelope Void](./connect_resources_esign_envelope_void.htm.md)**  
  Expire or void envelopes associated with an object.
- **[E-signature Notification](./connect_resources_esign_notification_settings.htm.md)**  
  Get e-signature notification settings.
- **[E-signature Recipients](./connect_resources_esign_recipients.htm.md)**  
  Get list of e-signature recipients.
- **[E-signature Signer Roles](./connect_resources_esign_signer_roles.htm.md)**  
  Get e-signature signer roles.
