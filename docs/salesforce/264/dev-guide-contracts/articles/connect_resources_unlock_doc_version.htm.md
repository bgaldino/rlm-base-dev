# Unlock Document Version

Unlock latest contract document version.

## Resource

```
/connect/clm/contract-document-version/$CONTRACT_DOCUMENT_VERSION_ID/unlock
```

## Available Version

56.0

## HTTP Methods

PATCH

## Example for PATCH

```
https://YOUR_INSTANCE.salesforce.com/services/data/v56.0/connect/clm/contract-document-version/${contractDocumentVersionId}/unlock
```
