# Document Playbook Resources

Retrieve playbook content that matches a query, and create playbook versions from
      uploaded content documents. Use these resources to power playbook-based guidance and risk
      analysis for contract documents.

      
         

The available resources are:

         

               
               
               
                  
                     

                     

                  

               

               
                  
                     

                     

                  

                  
                     

                     

                  

               

            
| Resource | Description |
| --- | --- |
| [`/connect/document-playbook/document-playbook-contents`](./connect_resources_document_playbook_contents.htm.md) (GET) | Get the playbook content chunks that match a user query by using vector similarity search. |
| [`/connect/document-playbook/document-playbook-version`](./connect_resources_document_playbook_version.htm.md) (POST) | Create a playbook version and link it to a content document. |

      

   

- 
**[Document Playbook Contents (GET)](./connect_resources_document_playbook_contents.htm.md)**  

Get the playbook content chunks that match a user query by using       vector similarity search.

- 
**[Document Playbook Version (POST)](./connect_resources_document_playbook_version.htm.md)**  

Create a playbook version and link it to a content       document.
