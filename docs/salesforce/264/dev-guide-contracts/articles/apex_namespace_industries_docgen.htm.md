# industries_docgen Namespace

The `industries_docgen` namespace provides classes
    and methods for document generation and permission management in Salesforce
    Industries.

The following are the classes in the `industries_docgen` namespace.

- 
**[DocGenPermsAndAccessChecksService Class](./apex_class_industries_docgen_DocGenPermsAndAccessChecksService.htm.md#apex_class_industries_docgen_DocGenPermsAndAccessChecksService)**  

The       `DocGenPermsAndAccessChecksService` class contains     methods to check permissions and settings related to document generation and integration     features.

- 
**[DocumentGenerationProcess Class](./apex_class_industries_docgen_DocumentGenerationProcess.htm.md#apex_class_industries_docgen_DocumentGenerationProcess)**  

The `DocumentGenerationProcess` class provides methods         to manage document generation processes.

- 
**[DocumentTemplate Class](./apex_class_industries_docgen_DocumentTemplate.htm.md#apex_class_industries_docgen_DocumentTemplate)**  

The `DocumentTemplate` class provides methods to manage         document generation         templates.
