# ContractTypeConfig

The settings that define the characteristics and behavior of all contracts of that type. This object is available in API version 56.0 and later.

    

## Supported Calls

      
      

`create()`, `delete()`, `describeSObjects()`, `query()`, `retrieve()`, `update()`, `upsert()`

    

  

    

## Fields

    
      

### ConfigType

        
        

**Type:** picklist

        

**Properties:** Create, Defaulted on create, Filter, Group, Nillable, Restricted picklist, Sort, Update

        

**Description:** The name of the configuration setting.

        

Possible values are:

        
          
- 
`ActivateObligationsBasedOnContractStatus`—Activate Obligations Based On Contract Status

          
- 
`AsyncCheckInEnabled`—Use asynchronous processing for document check-in

          
- 
`Append0ToAutoNbrEmbeddedSect`—Append Zero To Auto Number Of Embedded Section

          
- 
`AutoGenDocOnContractCreation`—Auto Generate Document On Contract Creation

          
- 
`AutoGenDocOnContractUpdate`—Auto Generate Document On Contract Update

          
- 
`AutoGenerateDocFileType`—Auto Generate Doc File Type

          
- 
`CheckInDocFileType`—Check In Document File Type

          
- 
`CompareContractVersionsEnabled`—Compare Contract Versions Enabled

          
- 
`ContractDocumentDownloadOption`—Contract Document Download Option

          
- 
`ContractSignatureDeclinedSts`—Contract Signature Declined Status

          
- 
`ContractSignatureExpiredStatus`—Contract Signature Expired Status

          
- 
`ContractSignatureVoidedStatus`—Contract Signature Voided Status

          
- 
`ContractSignedStatus`—Contract Signed Status

          
- 
`CreateDocSectionsDocxTemplates`—Create Document Sections for Docx Templates

          
- 
`DefaultTemplateName`—Default Template Name

          
- 
`DocuSignAccountBrand`—DocuSign Account Brand

          
- 
`DocuSignExpireEnabled`—DocuSign Expire Enabled

          
- 
`DocuSignExpireWarning`—DocuSign Expire Warning

          
- 
`DocuSignExpiresAfter`—DocuSign Expires After

          
- 
`DocuSignReminderDelayinDays`—DocuSign Reminder Delay In Days

          
- 
`DocuSignReminderEnabled`—DocuSign Reminder Enabled

          
- 
`DocuSignReminderFrequency`—DocuSign Reminder Frequency

          
- 
`DocuSignUseAccountDefaultNtfcn`—DocuSign Use Account Default Notification

          
- 
`DocumentFileNameFormat`—Document File Name Format

          
- 
`DocumentTemplateFilterClass`—Document Template Filter Class

          
- 
`EmailNotificationOnDocumentGeneration`—Email Notification On Document Generation

          
- 
`ExternalReviewRequired`—External Review Required

          
- 
`ImportTargetContractStatus`—Import Target Contract Status

          
- 
`InclWordTrackChgReconciliation`—Include Word Track Changes In Reconciliation

          
- 
`InclWordTrackChgSectionContent`—Include Word Track Changes In Section Content

          
- 
`InternalReviewRequired`—Internal Review Required

          
- 
`NotifyDocTemplateVerChgStatus`—Notify Document Template Version Change In Status

          
- 
`PrivateExternalReviewCompletionSite`—External Private Review Guest Site Name

          
- 
`TrackContractRedlines`—Track Contract Redlines

          
- 
`WordTrackChangesDisplayColor`—Word Track Changes Display Color

        

        

The default value is 'ContractDocumentDownloadOption'.

      

      

### ConfigValue

        
        

**Type:** textarea

        

**Properties:** Create, Nillable, Update

        

**Description:** The value of the configuration setting specified in the Configuration Name field.

      

      

### ContractTypeId

        
        

**Type:** reference

        

**Properties:** Create, Filter, Group, Sort

        

**Description:** The ID of the related Contract Type.

        

This is a relationship field.

        

**Relationship Name:** ContractType

        

**Relationship Type:** Lookup

        

**Refers To:** ContractType

      

      

### UsageType

        
        

**Type:** picklist

        

**Properties:** Create, Defaulted on create, Filter, Group, Nillable, Restricted picklist, Sort, Update

        

**Description:** The usage type to which this setting belongs.

        

Possible values are `DocumentSetting`, `Reconciliation`, `Redlining`, or `SignatureSetting`

        

The default value is 'DocumentSetting'.
