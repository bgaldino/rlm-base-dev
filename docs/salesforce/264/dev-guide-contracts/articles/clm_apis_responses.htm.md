# Response Bodies

Here’s a list of Salesforce Contracts response bodies.

- 
**[Clause Library Category Response](./connect_responses_clause_categories_respons.htm.md)**  

Output representation of the request to retrieve the clause library       category configuration.

- 
**[Clause Category Response](./connect_responses_clause_category_respons.htm.md)**  

Output representation of the field-level details for a clause category.

- 
**[Clause Library Category Response](./connect_responses_clause_library_category_respons.htm.md)**  

Response for getting Clause Library Category     configuration.

- 
**[Content Document](./connect_responses_content_document.htm.md)**  

Output representation of the content document record.

- 
**[Content Document List](./connect_responses_content_document_list_respons.htm.md)**  

Output representation of the content document record     list.

- 
**[Content Document Response](./connect_responses_connect_api._content_document_respons.htm.md)**  

Output representation of the individual content documents.

- 
**[Content Link Data Sync](./connect_responses_content_link_data_sync_output.htm.md)**  

Output representation that contains the details of data synchronization with success and     failure information.

- 
**[Content Link Data Sync Detail](./connect_responses_content_link_data_sync_detail.htm.md)**  

Output representation that contains content link details for the requested     IDs.

- 
**[Content Link List](./connect_responses_content_link_list.htm.md)**  

Output representation of the content data for the specified reference IDs.

- 
**[Content Link Detail](./connect_responses_content_link_detail.htm.md)**  

Output representation of the content link details for the specified reference     IDs.

- 
**[Contract Action List](./connect_responses_contract_action_list_respns.htm.md)**  

List of contract actions.

- 
**[Contract Action Response](./connect_responses_contract_action_respons.htm.md)**  

Contract action response for a particular contract     ID.

- 
**[Contract Document Version](./connect_responses_contract_document_version.htm.md)**  

Contract document version record.

- 
**[Contract Document Version CC Response](./connect_responses_contract_document_version_c_c.htm.md)**  

Output representation of the latest details of a contract document version, including its     ID, status, and associated documents and attachments.

- 
**[Contract Document Versions List](./connect_responses_contract_document_versions_list.htm.md)**  

Contract document versions record list.

- 
**[Contract List](./connect_responses_contract_output_response.htm.md)**  

Contract list.

- 
**[Contract Risk Analysis Run](./connect_responses_contract_risk_analysis_run_output.htm.md)**  

Output representation of the status and results of a contract document version risk analysis run.

- 
**[Contract Risk Analysis Element](./connect_responses_contract_risk_analysis_element_output.htm.md)**  

Output representation of an individual document element extracted and processed during risk analysis, including its content and the risk finding.

- 
**[Contract Risk Analysis Finding](./connect_responses_contract_risk_analysis_finding_output.htm.md)**  

Output representation of the risk analysis for a document element, capturing the identified risk, how the element compares to the playbook, and the recommended remediation.

- 
**[Contract Risk Analysis Error](./connect_responses_contract_risk_analysis_error_output.htm.md)**  

Output representation of the error code and error message returned       when a contract risk analysis request is unsuccessful.

- 
**[Document Clause Fields Response](./connect_responses_document_clause_fields_respons.htm.md)**  

Output representation for the list of document clause     fields.

- 
**[Document Clause Set List Response](./connect_responses_document_clause_set_list_respons.htm.md)**  

Output representation for the list of document clause     set.

- 
**[Document Clause Set Response](./connect_responses_document_clause_set_respons.htm.md)**  

Output representation of the details of a clause set.

- 
**[Document Generate](./connect_responses_document_generate.htm.md)**  

Output Representation of document generation record.

- 
**[Document Generation Process Status](./connect_responses_document_generation_process_status.htm.md)**  

Status of the document generation process.

- 
**[Document List](./connect_responses_document_list_respons.htm.md)**  

Document record list.

- 
**[Document Recipient Status](./connect_responses_document_recipient_status_c_c.htm.md)**  

Output representation of recipient status and sequence information for the     signers.

- 
**[Document Record](./connect_responses_document_respons.htm.md)**  

Document record.

- 
**[Document Template List](./connect_responses_document_template_list.htm.md)**  

Output representation for the document template list.

- 
**[Document Template Parent](./connect_responses_document_template_parent.htm.md)**  

Output representation of the document template parent record.

- 
**[Document Template Child](./connect_responses_document_template_child.htm.md)**  

Output representation of the document template child record.

- 
**[Document Template](./connect_responses_document_template.htm.md)**  

Output representation for the document template record.

- 
**[Envelope Details](./connect_responses_envelope_send_respons.htm.md)**  

Envelope details.

- 
**[Envelope Status List](./connect_responses_envelope_status_list_respons.htm.md)**  

Output representation of the envelope status update     request.

- 
**[Envelope Status](./connect_responses_envelope_status_respons.htm.md)**  

Output representation of the envelope status record.

- 
**[Envelope Void](./connect_responses_envelope_void_respons.htm.md)**  

Void envelope related details.

- 
**[External Document Creation Output](./connect_responses_external_doc_creation_output.htm.md)**  

Output representation for the create external document     request.

- 
**[External Document Output](./connect_responses_external_document_output.htm.md)**  

Output representation of the details of an external     document.

- 
**[External Document Review CC](./connect_responses_external_document_review_c_c.htm.md)**  

Output representation for external document version review.

- 
**[Extraction Context Attribute](./connect_responses_extraction_context_attribute_mapping.htm.md)**  

Output representation of extraction context attribute mapping.

- 
**[Extraction Context Definition](./connect_responses_extraction_context_definition.htm.md)**  

Output representation of extraction context definition details.

- 
**[Extraction Context Mapping](./connect_responses_extraction_context_mapping.htm.md)**  

Output representation of mapping details within an extraction context, used to associate     extracted data with specific system entities.

- 
**[Extraction Context Mapping](./connect_responses_extraction_context_mapping_output.htm.md)**  

Output representation of extraction context mapping.

- 
**[Extraction Context Mappings](./connect_responses_extraction_context_mappings_output.htm.md)**  

Output Representation to create and update extraction context mapping.

- 
**[Extraction Context Use Case Mapping](./connect_responses_extraction_context_use_case_mapping.htm.md)**  

Output representation of extraction context use case mapping.

- 
**[Failed Content Link List](./connect_responses_failed_content_link_list.htm.md)**  

Output representation of the content ID and error details for the failed     requests.

- 
**[Generic Output](./connect_responses_generic_output.htm.md)**  

Generic output response.

- 
**[Playbook Contents](./connect_responses_playbook_contents_output.htm.md)**  

Output representation that contains the playbook version ID and the       matching content chunks.

- 
**[Playbook Chunk](./connect_responses_playbook_chunk.htm.md)**  

Output representation of a single playbook content chunk and its       similarity score.

- 
**[Playbook Version Details](./connect_responses_playbook_version_details.htm.md)**  

Output representation that contains the ID of the created playbook       version.

- 
**[Recipient Details](./connect_responses_recipient_respons.htm.md)**  

Recipient details.

- 
**[Recipient List](./connect_responses_recipient_list_respons.htm.md)**  

List of recipients.

- 
**[Recipients Response](./connect_responses_recipient_output.htm.md)**  

Output representation of a recipient’s personal and status information in a contract     document’s signing process.

- 
**[Save External Document Output](./connect_responses_save_external_document.htm.md)**  

Output representation for save external document     operation.

- 
**[Signer Roles Details](./connect_responses_signer_roles_respons.htm.md)**

**[Template List](./connect_responses_template_list.htm.md)**

**[E-signature Notification Reminder](./connect_responses_notification_reminder_respons.htm.md)**  

E-signature notification reminder settings.

- 
**[E-signature Notification Settings](./connect_responses_notification_setting_respons.htm.md)**  

E-signature notification settings.
