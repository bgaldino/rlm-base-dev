# Response Bodies

Learn more about the available Product Configurator API response bodies.

- 

**[Configuration Details](./connect-responses-configurator-output.md)**

Output representation of the product configuration details.

- 

**[Configuration Get Instance](./connect-responses-get-configuration-instance-output.md)**

Output representation of the request to retrieve the configuration instance.

- 

**[Configuration Load Instance](./connect-responses-load-configuration-instance-output.md)**

Output representation of the details of the context or session that are returned with a load configuration request.

- 

**[Configuration Save Details](./connect-responses-favorite-output-represenation.md)**

Output representation of the details of a saved configuration.

- 

**[Configuration Record Save](./connect-responses-create-favorite-output.md)**

Output representation of the details of a saved configuration.

- 

**[Configuration List](./connect-responses-favorite-list-output-represenation.md)**

Output representation of the details of the saved configuration.

- 

**[Configuration Save Instance](./connect-responses-save-configuration-instance-output.md)**

Output representation of the response that’s returned with a save configuration request.

- 

**[Configuration Set Instance](./connect-responses-set-configuration-instance-output.md)**

Output representation of the details of the context or session that are returned with a set configuration request.

- 

**[Configurator Add Nodes](./connect-responses-add-nodes-configurator-output.md)**

Output representation of the configuration request details to add nodes.

- 

**[Configurator Additional Fields](./connect-responses-configurator-additional-fields-output.md)**

Output representation of the additional fields of a product configuration.

- 

**[Configurator Attribute](./connect-responses-configurator-attribute-output.md)**

Output representation of the attribute in a product configuration.

- 

**[Configurator Attribute Category](./connect-responses-configurator-attribute-category-output.md)**

Output representation of the attribute category in a product configuration.

- 

**[Configurator Attribute Picklist](./connect-responses-configurator-attribute-picklist-output.md)**

Output representation of the attribute picklist in a product configuration.

- 

**[Configurator Attribute Picklist Value](./connect-responses-configurator-attribute-picklist-value-output.md)**

Output representation of the values of an attribute picklist in a product configuration.

- 

**[Configurator Delete Nodes](./connect-responses-delete-nodes-configurator-output.md)**

Output representation of the details of the configuration request to delete nodes.

- 

**[Configurator Message](./connect-responses-configurator-message-output.md)**

Output representation of the messages of a product configurator.

- 

**[Configurator Price](./connect-responses-configurator-price-output.md)**

Output representation of the pricing details in a product configuration.

- 

**[Configurator Pricing Model](./connect-responses-configurator-pricing-model-output.md)**

Output representation of the details of a pricing model in a product configuration.

- 

**[Configurator Product Catalog](./connect-responses-configurator-product-catalog-output.md)**

Output representation of the product catalog.

- 

**[Configurator Product Classification](./connect-responses-configurator-product-classification-output.md)**

Output representation of the product classification in a product configuration.

- 

**[Configurator Product Component Group](./connect-responses-configurator-product-component-group-output.md)**

Output representation of the product component group in a product classification.

- 

**[Configurator Product Recommendations](./connect-responses-configurator-product-recommendation-output.md)**

Output representation of the details of the product recommendations.

- 

**[Configurator Product Related Component](./connect-responses-configurator-product-related-component-output.md)**

Output representation of the product related component in a product configuration.

- 

**[Configurator Product Selling Model](./connect-responses-configurator-product-selling-model-output.md)**

Output representation of the product selling model in a product configuration.

- 

**[Configurator Product Selling Model Option](./connect-responses-configurator-product-selling-model-option-output.md)**

Output representation of the product selling model option in a product configuration.

- 

**[Configurator Qualification Context](./connect-responses-configurator-qualification-context-output.md)**

Output representation of the qualification context in a product configuration.

- 

**[Configurator UI Treatment](./connect-responses-configurator-u-i-treatment-output.md)**

Output representation of the details of the UI treatments of a product configurator. The details include the product configuration rule actions to override the disable or hide behavior in the UI for product options, product attributes, and attribute picklist values.

- 

**[Configurator Unit Of Measure](./connect-responses-configurator-unit-of-measure-output.md)**

Output representation of the details of the unit of measure record.

- 

**[Configurator Update Nodes](./connect-responses-update-nodes-configurator-output.md)**

Output representation of the configuration request details to update nodes.

- 

**[Configuration Update](./connect-responses-update-favorite-output.md)**

Output representation of the details of the updated configuration.

- 

**[Error Response](./connect-responses-configuration-list-error-response.md)**

Output representation of the details of the error.

- 

**[Product Quantity Set Configurator](./connect-responses-set-product-quantity-configurator-output.md)**

Output representation of the request details to set product quantity.

- 

**[Configuration Rule Response](./connect-responses-config-rule-output.md)**

Output representation of the details of the configuration rule response.
