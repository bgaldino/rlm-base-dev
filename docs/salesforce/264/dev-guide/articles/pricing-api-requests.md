# Request Bodies

Learn more about the available Salesforce Pricing API request bodies.

- 

**[Adjustment Details Input](./connect-requests-adjustment-details-input.md)**

Input representation of the adjustment details.

- 

**[Configuration Override Input](./connect-requests-configuration-override-input.md)**

Input representation of the details to override for a Pricing API configuration.

- 

**[PBE Derived Pricing Input](./connect-requests-p-b-e-derived-pricing-input.md)**

Input representation of the request to get the source product for the Price Book Entry (PBE) derived pricing.

- 

**[Pricing Input](./connect-requests-core-pricing-input.md)**

Input representation of the details of a Pricing API request.

- 

**[Pricing Recipe Clone Input](./connect-requests-pricing-recipe-clone-input.md)**

Input representation to clone a pricing recipe.

- 

**[Pricing Recipe Input](./connect-requests-pricing-recipe-input.md)**

Input representation to set up a pricing recipe page.

- 

**[Pricing Recipe LookUp Table Input](./connect-requests-pricing-recipe-look-up-table-input.md)**

Input representation of the lookup tables for the setup page recipe.

- 

**[Pricing Recipe Procedure Input](./connect-requests-pricing-recipe-procedure-input.md)**

Input representation of the procedure for the setup page recipe.

- 

**[Pricing Request Input](./connect-requests-pricing-request.md)**

Input representation of a pricing request.

- 

**[Pricing Versioned Revision Details Input](./connect-requests-pricing-versioning-revise-details-input.md)**

Input representation of the versioned revision details.

- 

**[Pricing Waterfall Input](./connect-requests-pricing-waterfall-input.md)**

Input representation of the pricing waterfall details.

- 

**[Pricing Waterfall Log Input](./connect-requests-pricing-waterfall-log-input.md)**

Input representation of the request to create an explainability action log.

- 

**[Procedure Plan Criterion Input](./connect-requests-procedure-plan-criterion-input.md)**

Input representation of the details of a procedure plan criterion.

- 

**[Procedure Plan Definition Input](./connect-requests-procedure-plan-definition-input.md)**

Input representation of the details of a procedure plan definition.

- 

**[Procedure Plan Definition Version Input](./connect-requests-procedure-plan-definition-version-input.md)**

Input representation of the details of a procedure plan definition version.

- 

**[Procedure Plan Evaluation Input](./connect-requests-procedure-plan-evaluation-input.md)**

Input representation of the details used to evaluate a procedure plan definition.

- 

**[Procedure Plan Section Input](./connect-requests-procedure-plan-section-input.md)**

Input representation of the details of a procedure plan section.

- 

**[Procedure Plan Option Input](./connect-requests-procedure-plan-option-input.md)**

Input representation of the details of a procedure plan option.
