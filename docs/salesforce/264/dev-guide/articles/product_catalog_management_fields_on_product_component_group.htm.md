# Product Catalog Management Fields on Product Component Group

Standard and custom fields extend the standard Product Component Group object
for use in Product Catalog Management.

#### See Also

- [Product Component Group](https://developer.salesforce.com/docs/atlas.en-us.264.0.object_reference.meta/object_reference/sforce_api_objects_productcomponentgroup.htm "Product Component Group - HTML (New Window)")

## Fields

### ParentGroupId

**Type:** reference

**Properties:** Create, Filter, Group, Nillable, Sort, Update

**Description:** The parent product component group in a nested group hierarchy for the same parent product. Available in API version 62.0 and later.

This field is a relationship field.

**Relationship Name:** ParentGroup

**Refers To:** ProductComponentGroup
