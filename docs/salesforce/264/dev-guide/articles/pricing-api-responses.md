# Response Bodies

Learn more about the available Salesforce Pricing API response bodies.

- 

**[Adjustment Details](./connect-responses-adjustment-detail.md)**

Output representation of a pricing adjustment request.

- 

**[API Execution Log Response](./connect-responses-api-execution-log.md)**

Output representation of the execution log of a pricing waterfall request.

- 

**[Line Item Waterfall Response](./connect-responses-line-item-waterfall-response.md)**

Output representation of the line item waterfall response.

- 

**[PBE Derived Pricing](./connect-responses-p-b-e-derived-pricing-out-put.md)**

Output representation of the response that includes the source product for the Price Book Entry (PBE) derived pricing.

- 

**[Pricing Error Response](./connect-responses-pricing-error-response.md)**

Output representation of the pricing error response.

- 

**[Pricing Execution Waterfall Response](./connect-responses-api-execution-waterfall-response.md)**

Output representation of the execution process that’s associated with a pricing waterfall.

- 

**[Pricing Generic Response](./connect-responses-pricing-generic-response.md)**

Output representation of a pricing data sync request.

- 

**[Pricing Output](./connect-responses-core-pricing-output.md)**

Output representation of a Salesforce pricing request.

- 

**[Pricing Recipe LookUp Table Response](./connect-responses-pricing-recipe-look-up-table-response.md)**

Output representation of a pricing recipe lookup table.

- 

**[Pricing Recipe](./connect-responses-pricing-recipe-output.md)**

Output representation of the pricing recipe information table.

- 

**[Pricing Recipe Post](./connect-responses-pricing-recipe-post-output.md)**

Output representation of the pricing recipe after the API request.

- 

**[Pricing Recipe Response](./connect-responses-pricing-recipe-response.md)**

Output representation of the pricing recipe.

- 

**[Pricing Recipe Clone](./connect-responses-pricing-recipe-clone-output.md)**

Output representation of the payload for the pricing recipe clone operation.

- 

**[Pricing Recipe Clone Error](./connect-responses-pricing-recipe-clone-error.md)**

Output representation of the error response for the Pricing Recipe Clone API.

- 

**[Pricing Recipe Valid Elements](./connect-responses-pricing-valid-elements-output.md)**

Output representation containing the list of valid pricing element type API names for a given Pricing Usage Sub Type.

- 

**[Pricing Response](./connect-responses-pricing-response.md)**

Output representation of the pricing request.

- 

**[Pricing Result](./connect-responses-core-pricing-result.md)**

Output representation of the pricing result.

- 

**[Pricing Result Error](./connect-responses-core-pricing-result-error.md)**

Output representation of the pricing result error.

- 

**[Pricing Versioned Revision Details](./connect-responses-pricing-versioned-revise-details-output.md)**

Output representation of the versioned revision details.

- 

**[Pricing Waterfall Response](./connect-responses-pricing-water-fall-response.md)**

Output representation of a pricing waterfall request.

- 

**[Procedure Plan Criterion](./connect-responses-procedure-plan-criterion-output.md)**

Output representation of the details of a procedure plan criterion.

- 

**[Procedure Plan Definition](./connect-responses-procedure-plan-definition-output.md)**

Output representation of the details of a single procedure plan definition.

- 

**[Procedure Plan Definition Version](./connect-responses-procedure-plan-definition-version-output.md)**

Output representation of the version details of a procedure plan definition.

- 

**[Procedure Plan Definitions](./connect-responses-procedure-plan-definitions-output.md)**

Output representation of the details of procedure plan definitions.

- 

**[Procedure Plan Generic](./connect-responses-procedure-plan-generic-output.md)**

Output representation of the details of the created procedure plan definition record.

- 

**[Procedure Plan Generic Error](./connect-responses-procedure-plan-generic-error.md)**

Output representation of the error details related to the procedure plan definitions.

- 

**[Procedure Plan Option](./connect-responses-procedure-plan-option-output.md)**

Output representation of the details of a procedure plan option.

- 

**[Procedure Plan Section](./connect-responses-procedure-plan-section-output.md)**

Output representation of the details of a procedure plan section.

- 

**[Procedure Plan Section Evaluation Runtime](./connect-responses-procedure-plan-section-evaluation-runtime.md)**

**[Procedure Plan Evaluation Result](./connect-responses-procedure-plan-evaluation-result.md)**

Output representation of the evaluation result of a procedure plan definition.

- 

**[Pricing Process Execution Details for Line Items](./connect-responses-process-execution-line-item-details-get-output.md)**

Output representation of the pricing process execution details for the line items along with the error details and response generation status.

- 

**[Line Item Details Response](./connect-responses-process-execution-line-item-details-response.md)**

Output representation of the pricing process execution details for the line items.

- 

**[Pricing Process Execution Response](./connect-responses-pricing-process-execution-get-output.md)**

Output representation of the details of a pricing process execution.

- 

**[Pricing Process Execution List](./connect-responses-pricing-process-execution-output.md)**

Output representation of the execution details for different types of the pricing processes.

- 

**[Pricing Simulation Input Variables With Data](./connect-responses-pricing-simulation-input-variables-with-data-output.md)**
