# Product Catalog Management Fields on Product Selling Model Option

Standard and custom fields extend the standard Product Selling Model Option object for use in Product Catalog Management. This object is available in API version 60.0 and later.

**See Also**

- [Product Selling Model Option](https://developer.salesforce.com/docs/atlas.en-us.object_reference.meta/object_reference/sforce_api_objects_productsellingmodeloption.htm)

## Fields

### IsDefault

**Type:** boolean

**Properties:** Create, Defaulted on create, Filter, Group, Sort, Update

**Description:** Indicates the default product selling model for a product. Setting a product selling model as default is optional. A product can only have one default product selling model.

The default value is `false`.
