# Response Bodies

Learn more about the available Product Discovery API response bodies.

- 

**[API Status](./connect-responses-api-status-output.md)**

Output representation of the API status.

- 

**[Catalog Details](./connect-responses-product-discovery-catalog-output.md)**

Output representation of the details of a catalog definition.

- 

**[Category Details](./connect-responses-product-discovery-category-output.md)**

Output representation of the details of a category.

- 

**[Bulk Product Details](./connect-responses-cpq-base-bulk-details-output.md)**

Output representation of the response that contains the details of multiple products.

- 

**[CPQ Base Details](./connect-responses-cpq-base-details-output.md)**

Output representation of the catalog, category, or product details based on the request.

- 

**[CPQ Base List](./connect-responses-cpq-base-list-output.md)**

Output representation of the list of catalogs, categories, or products based on the request.

- 

**[CPQ Message](./connect-responses-cpq-message-output.md)**

Output representation of the API messages.

- 

**[Facet Value](./connect-responses-facet-value.md)**

Output representation of the facet values found in the search result.

- 

**[Guided Selection](./connect-responses-guided-selection-output.md)**

Output representation of the details of a guided selection.

- 

**[Guided Selection Search Term](./connect-responses-guided-selection-search-term-output.md)**

Output representation of the search term details for a guided selection.

- 

**[Pricing Model](./connect-responses-pricing-model-output.md)**

Output representation of the details of the pricing model.

- 

**[Product Classification](./connect-responses-product-discovery-product-classification-output.md)**

Output representation of the details of a product classification.

- 

**[Product Configuration Rule Details](./connect-responses-product-configuration-rule-details-output.md)**

Output representation of the product configuration rule details.

- 

**[Product Configuration Rules](./connect-responses-product-configuration-rules-output.md)**

Output representation of the details of the product configuration rules.

- 

**[Product Prices](./connect-responses-product-prices-output.md)**

Output representation of the details of the product prices.

- 

**[Product Quantity](./connect-responses-product-quantity-output.md)**

Output representation of the details of the quantity constraints and current quantity for a product in the product discovery context.

- 

**[Product Recommendation Errors](./connect-responses-product-recommendation-errors-output.md)**

Output representation of the details of the errors encountered during the processing of the Product Recommendations API request.

- 

**[Product Recommendations](./connect-responses-product-recommendation-output.md)**

Output representation of the fetched product recommendations.

- 

**[Product Selling Model Option](./connect-responses-product-discovery-product-selling-model-option-output.md)**

Output representation of the product selling model option component.

- 

**[Product Selling Model](./connect-responses-product-discovery-product-selling-model-output.md)**

Product Selling Model Component output representation

- 

**[Product Specification Record Type](./connect-responses-product-specification-record-type-output.md)**

Output representation of the details of the product specification record type.

- 

**[Product Specification Type](./connect-responses-product-discovery-product-specification-type-output.md)**

Output representation of the details of the product specification type.

- 

**[Promotion Details](./connect-responses-promotion-output.md)**

Output representation of the details of applicable promotions.

- 

**[Proration Policy](./connect-responses-proration-policy-output.md)**

Output representation of the details of the proration policy component.

- 

**[Qualification Context](./connect-responses-qualification-context-output.md)**

Output representation of the details about the product qualification.

- 

**[Recommended Products](./connect-responses-recommended-products-output.md)**

Output representation of the list of recommended products.

- 

**[Search Products Facet](./connect-responses-search-products-facet.md)**

Output representation of the details of the faceted search.

- 

**[User Context](./connect-responses-user-context-output.md)**

Output representation of the user context details.
