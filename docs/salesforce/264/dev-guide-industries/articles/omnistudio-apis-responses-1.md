# Response Bodies

Here’s a list of Decision Matrix API (also known as Calculation Matrix) response bodies.

- 

**[Decision Matrix Basic](./connect-responses-decision-matrix-basic.md)**

Output representation of the decision matrices details.

- 

**[Decision Matrix Result](./connect-responses-decision-matrix-result.md)**

Output representation of the decision matrix details.

- 

**[Decision Matrix Result List](./connect-responses-decision-matrix-result-list.md)**

Output representation of the decision matrix result list.

- 

**[Decision Matrix Variable](./connect-responses-decision-matrix-variable.md)**

Details of the input or output variables of a decision matrix.

- 

**[Decision Matrix Columns Output](./connect-responses-decision-matrix-columns-output.md)**

Output representation of columns of a decision matrix.

- 

**[Decision Matrix Column Output](./connect-responses-decision-matrix-column-output.md)**

Representation of the details of a column in a decision matrix.

- 

**[Decision Matrix Rows Output](./connect-responses-decision-matrix-rows-output.md)**

Output representation of rows of a decision matrix version.

- 

**[Decision Matrix Row Output](./connect-responses-decision-matrix-row-output.md)**

Representation of the details of a row in a decision matrix version.

- 

**[Decision Matrix Output](./connect-responses-decision-matrix-output.md)**

Output representation the action performed on a decision matrix version.
