# Request Bodies

Expression Set API includes these request bodies.

- 

**[Business Rules Input](./connect-requests-business-rules-input.md)**

Input representation of an expression set.

- 

**[Context Definition Input](./connect-requests-context-definition-input.md)**

Input representation of the context definitions in an expression set.

- 

**[Expression Set Advanced Condition Step Input](./connect-requests-expression-set-advanced-condition-step.md)**

Input representation of an advanced condition step in an expression set.

- 

**[Expression Set Aggregation Step Input](./connect-requests-expression-set-aggregation-step.md)**

Input representation of an aggregation step in an expression set.

- 

**[Expression Set Assignment Step Input](./connect-requests-expression-set-assignment-step.md)**

Input representation of an assignment step in an expression set.

- 

**[Expression Set Condition Criteria Input](./connect-requests-expression-set-condition-criteria.md)**

Input representation of a condition criteria in an expression set.

- 

**[Expression Set Condition Expression Step](./connect-requests-expression-set-condition-expression-step.md)**

Input representation of an expression set condition step.

- 

**[Expression Set Custom Element Parameter Input](./connect-requests-expression-set-custom-element-parameter.md)**

Input representation of a custom element parameter in an expression set.

- 

**[Expression Set Custom Element Step Input](./connect-requests-expression-set-custom-element-step.md)**

Input representation of a custom element step in an expression set.

- 

**[Expression Set DES Token Mapping Input](./connect-requests-expression-set-des-token-mapping.md)**

Input representation of the DES token mapping in an expression set version step.

- 

**[Expression Set Input](./connect-requests-expression-set-input.md)**

Input representation of the expression set create and update request.

- 

**[Expression Set Lookup Table Step Input](./connect-requests-expression-set-lookup-table-step.md)**

Input representation of a lookup table step in an expression set.

- 

**[Expression Set Options Input](./connect-requests-options.md)**

Input representation of the options for executing an expression set.

- 

**[Expression Set SubExpression Step Input](./connect-requests-expression-set-sub-expression-step.md)**

Input representation of a subexpression step in an expression set.

- 

**[Expression Set Version Input](./connect-requests-expression-set-version.md)**

Input representation of an expression set version.

- 

**[Expression Set Version Step Input](./connect-requests-expression-set-version-step.md)**

Input representation of a step in an expression set version.

- 

**[Expression Set Version Variable Input](./connect-requests-expression-set-version-variable.md)**

Input representation of a variable in an expression set version.
