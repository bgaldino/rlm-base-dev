# Discovery Framework API Responses

Here’s the list of the Discovery Framework Document Decision API response bodies.

- 

**[Additional Attributes Output](./connect-responses-additional-attributes.md)**

Output representation of the Additional Attributes.

- 

**[Assessment Responses Output](./connect-responses-assessment-responses-output.md)**

Output of assessment responses.

- 

**[Custom Type Details](./connect-responses-custom-type-details.md)**

Output representation of the custom type details of the Omniscript elements.

- 

**[Decision Table Document Decision Output](./connect-responses-decision-table-document-decision.md)**

Decision Table output.

- 

**[Document Decision Output](./connect-responses-document-decision-response.md)**

Output representation of the Document Decision response, including Decision Table output.

- 

**[Document Types Output](./connect-responses-document-types.md)**

Output representation of the Document Type.

- 

**[Omniscript Elements List](./connect-responses-omniscript-elements-list.md)**

Output representation of the details of the Omniscript elements.

- 

**[Omniscript Output](./connect-responses-omniscript-output.md)**

Output representation of the details of the Omniscript.

- 

**[Omniscript Element Discovery Framework Output](./connect-responses-os-element-discovery-framework-output.md)**

Output representation of the custom type details of the Omniscript elements for Discovery Framework.

- 

**[Omniscript Element Property Set Output](./connect-responses-os-element-property-set-output.md)**

Output representation of the property set configuration of the Omniscript elements.
