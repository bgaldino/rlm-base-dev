# Integration Procedure Execution (POST)

Execute an integration procedure by using the name or ID of the integration
procedure.

## Resource

```
/connect/omni-global/integration-procedure/execute/id
```

## Resource Example

```
https://yourInstance.salesforce.com/services/data/v68.0/connect/omni-global/integration-procedure/execute/0jNxx000000005rFCC
```

## Available Version

64.0

## HTTP Methods

POST
