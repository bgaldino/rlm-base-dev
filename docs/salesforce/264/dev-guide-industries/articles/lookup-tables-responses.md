# Response Bodies

Lookup Table API includes these response bodies.

- 

**[Decision Matrix Lookup Basic Result](./connect-responses-decision-matrix-lookup-basic-result.md)**

Results from a Decision Matrix lookup using a single input.

- 

**[Decision Matrix Lookup Result](./connect-responses-bre-decision-matrix-lookup-result.md)**

Output representation of the individual output of a decision matrix version lookup.

- 

**[Decision Model Export Error](./connect-responses-decision-model-export-error.md)**

Error representation of a failed DMN (Decision Model Notation) export request.

- 

**[Decision Model Export Output](./connect-responses-decision-model-export-output.md)**

Output representation of a completed DMN (Decision Model Notation) export request.

- 

**[Decision Table Bulk Outcome](./connect-responses-decision-table-bulk-outcome.md)**

Output representation of the decision table bulk look-up.

- 

**[Decision Table Definition Output](./connect-responses-decision-table-definition-output.md)**

Output representation of a decision table definition associated with a decision table.

- 

**[Decision Table Outcome](./connect-responses-decision-table-outcome.md)**

Output representation of the decision table execution.

- 

**[Decision Table Outcome Item](./connect-responses-decision-table-outcome-item.md)**

Output representation of the decision table outcome item.

- 

**[Decision Table Output](./connect-responses-decision-table-output.md)**

Output representation of the decision table details.

- 

**[Decision Table Parameter Output](./connect-responses-decision-table-parameter-output.md)**

Output representation of a decision table parameter.

- 

**[Decision Table Source Criteria Output](./connect-responses-decision-table-source-criteria-output.md)**

Output representation of the decision table source criteria.

- 

**[Decision Table Data](./connect-responses-decision-table-data-output.md)**

Output representation of the status of an action performed.

- 

**[Decision Table Row](./connect-responses-decision-table-row-output.md)**

Output representation to describe the output of a decision table row.

- 

**[Decision Table Rows List](./connect-responses-decision-table-rows-list-output.md)**

Output representation of the rows in relation to the decision table, including current state of pagination.

- 

**[Lookup Table Details](./connect-responses-lookup-table-details.md)**

Output representation of the basic details of a lookup table.

- 

**[Lookup Tables Result List](./connect-responses-lookup-tables-result-list.md)**

Output representation of the result of a lookup table search request.
