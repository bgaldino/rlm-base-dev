# Response Bodies

Here’s a list of Decision Explainer API response bodies.

- 

**[Explainability Action Logs](./connect-responses-explainability-action-logs.md)**

Output representation of the list of Explainability action logs.

- 

**[Explainability Action Log Create](./connect-responses-explainability-action-log-create.md)**

Output representation of the create Explainability action log request.

- 

**[Explainability Action Log Detail](./connect-responses-explainability-action-log-detail.md)**

Output representation of the Explainability action log details.

- 

**[Explainability Detailed Action Log Detail](./connect-responses-explainability-detailed-action-log-detail.md)**

Output representation of explainability action log in detail.
