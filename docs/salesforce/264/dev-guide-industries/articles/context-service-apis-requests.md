# Request Bodies

Here’s a list of Context Service API request bodies.

- 

**[Context Attribute Mappings Input](./connect-requests-context-attribute-mappings-input.md)**

Input representation of context attribute mapping.

- 

**[Context Attribute Hydration Details Input](./connect-requests-context-attr-hydration-details-input.md)**

Input representation of context attribute hydration detail.

- 

**[Context Attributes Input](./connect-requests-context-attributes-input.md)**

Input representation of context attribute.

- 

**[Context Definition Input](./connect-requests-context-definitions-input.md)**

Input representation of the context definition.

- 

**[Context Definition Upgrade Input](./connect-requests-context-definition-upgrade.md)**

Input representation of context definition upgrade.

- 

**[Context Definition Filter Input](./connect-requests-context-definition-filter-input.md)**

Input representation details of context definition filter.

- 

**[Context Definition Filter List Input](./connect-requests-context-definition-filter-list-input.md)**

Input representation for a list of Context Definition Filters

- 

**[Context Input](./connect-requests-context-input.md)**

Input representation for defining a context.

- 

**[Context Mappings Input](./connect-requests-context-mappings-input.md)**

Input representation of context mapping.

- 

**[Context Metadata Input](./connect-requests-context-meta-data-input.md)**

Input representation of context metadata.

- 

**[Context Node ID Input](./connect-requests-context-node-id-input.md)**

Input representation of the list of context node IDs to create the relationship nodes for.

- 

**[Context Node Mapping Id (GET, DELETE)](./connect-resources-context-node-mapping-id.md)**

Query and delete a context node mapping using an ID.

- 

**[Context Node Mappings Input](./connect-requests-context-node-mappings-input.md)**

Input representation of context node mapping.

- 

**[Context Nodes Input](./connect-requests-context-nodes-input.md)**

Input representation of context node.

- 

**[Context Tag Input](./connect-requests-context-tag-input.md)**

Input representation of the context tag.

- 

**[Context Query Tags Leaner (POST)](./connect-resources-context-query-lean-tag.md)**

Query tags and return a memory-optimized (leaner) result suitable for Apex and low-heap clients. Eliminate redundant metadata to reduce heap usage and payload size.

- 

**[Leaner Query Tags Input](./connect-requests-leaner-query-tags-input.md)**

Input representation of the leaner query tags.

- 

**[Node Path and Tag Values Input](./connect-requests-node-path-and-tag-values.md)**

Input representation of the node path which needs to update with tag details.

- 

**[Context Data Path Input](./connect-requests-context-data-path-input.md)**

Input representation of the data path to a context record.

- 

**[Query Context Records and Children Input](./connect-requests-query-context-records-input.md)**

Input representation for querying context records and their child records.

- 

**[Query Record Status Input](./connect-requests-query-data-input.md)**

Input representation of status and related error messages of query data records.

- 

**[Query Persist Context](./connect-requests-query-persist-context-input.md)**

Persist context data to the system by providing the relevant context ID. The context and corresponding records will be persisted for further processing.

- 

**[Query Tags Input](./connect-requests-query-tags-input.md)**

Input representation of query tags to be created with a defined context.

- 

**[Tag Values Input](./connect-requests-tag-values-input.md)**

Input representation of the list of Tag Names to be updated and their values.
