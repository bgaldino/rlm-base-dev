# Request Bodies

Lookup Table API includes these request bodies.

- 

**[Decision Matrix Input](./connect-requests-decision-matrix-input.md)**

Input representation of the inputs passed to a decision matrix for lookup.

- 

**[Decision Matrix Lookup Input](./connect-requests-decision-matrix-lookup.md)**

Input representation of the input for a decision matrix lookup.

- 

**[Decision Matrix Options Input](./connect-requests-decision-matrix-options.md)**

Input representation of the options used to look up a decision matrix.

- 

**[Decision Matrix Variable Input](./connect-requests-decision-matrix-variable.md)**

Input representation of the variables in an input passed to a decision matrix lookup.

- 

**[Decision Model Export Input](./connect-requests-decision-model-export-input.md)**

Input representation of the request to export decision matrix data.

- 

**[Decision Table Bulk Input](./connect-requests-decision-table-bulk-input.md)**

Input representation of the Decision Table bulk lookup.

- 

**[Decision Table Condition Input](./connect-requests-decision-table-condition.md)**

Input representation of the decision table condition.

- 

**[Decision Table Condition List Input](./connect-requests-decision-table-condition-list-input.md)**

Input representation of the Decision Table condition list.

- 

**[Decision Table Input](./connect-requests-decision-table-input.md)**

Input representation of a decision table.

- 

**[Decision Table Definition Input](./connect-requests-decision-table-definition-input.md)**

Input representation of a decision table definition.

- 

**[Decision Table Parameter Input](./connect-requests-decision-table-parameter-input.md)**

Input representation of parameters defined for the decision table.

- 

**[Decision Table Source Criteria Input](./connect-requests-decision-table-source-criteria-input.md)**

Input representation of source criteria for the decision table.

- 

**[Decision Table Row List Input](./connect-requests-decision-table-row-list-input.md)**

Input representation of the data for a row in the CSV based decision table that has to be added or updated.

- 

**[Decision Table Rows List Input](./connect-requests-decision-table-rows-list-input.md)**

Input representation of the request to update rows in a CSV based decision table.
