# Omnistudio Standard Objects

Omnistudio data model defines the foundational objects and fields used across Omnistudio components. It enables consistent data access and management within guided experiences and process automation.

- 

**[OmniComponentErrorLog](./sforce-api-objects-omnicomponenterrorlog.md)**

For internal use only.

- 

**[OmniDataPack](./sforce-api-objects-omnidatapack.md)**

For internal use only.

- 

**[OmniDataTransform](./sforce-api-objects-omnidatatransform.md)**

For internal use only.

- 

**[OmniDataTransformItem](./sforce-api-objects-omnidatatransformitem.md)**

For internal use only.

- 

**[OmniESignature](./sforce-api-objects-omniesignature.md)**

For internal use only.

- 

**[OmniExtTrackingDef](./sforce-api-objects-omniexttrackingdef.md)**

Represents a connection between an OmniTrackingGroup in OmniAnalytics and a third-party Analytics system such as Google Analytics. This object is available in API version 60.0 and later.

- 

**[OmniExtTrackingEventDef](./sforce-api-objects-omniexttrackingeventdef.md)**

Represents a format for FlexCard or OmniScript user interaction data that a third-party Analytics system such as Google Analytics can accept. This object is available in API version 60.0 and later.

- 

**[OmniInteractionAccessConfig](./sforce-api-objects-omniinteractionaccessconfig.md)**

For internal use only.

- 

**[OmniInteractionConfig](./sforce-api-objects-omniinteractionconfig.md)**

For internal use only.

- 

**[OmniProcess](./sforce-api-objects-omniprocess.md)**

For internal use only.

- 

**[OmniProcessCompilation](./sforce-api-objects-omniprocesscompilation.md)**

For internal use only.

- 

**[OmniProcessElement](./sforce-api-objects-omniprocesselement.md)**

For internal use only.

- 

**[OmniProcessTransientData](./sforce-api-objects-omniprocesstransientdata.md)**

For internal use only.

- 

**[OmniScriptSavedSession](./sforce-api-objects-omniscriptsavedsession.md)**

For internal use only.

- 

**[OmniTrackingComponentDef](./sforce-api-objects-omnitrackingcomponentdef.md)**

Represents a FlexCard or OmniScript that is a member of an OmniTrackingGroup, which tracks user interactions in OmniAnalytics. This object is available in API version 60.0 and later.

- 

**[OmniTrackingGroup](./sforce-api-objects-omnitrackinggroup.md)**

Represents a group of FlexCard and OmniScript components that have their user interactions tracked together in OmniAnalytics. This object is available in API version 60.0 and later.

- 

**[OmniUiCard](./sforce-api-objects-omniuicard.md)**

For internal use only.
