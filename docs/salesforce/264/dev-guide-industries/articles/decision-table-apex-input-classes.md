# Input Classes

These are Decision Table Apex input classes.

- 

**[ConnectApi.DecisionTableInput](./apex-connectapi-input-decision-table.md)**

Input representation of the decision table.

- 

**[ConnectApi.DecisionTableCondition](./apex-connectapi-input-decision-table-condition-representatio.md)**

Input representation of the decision table condition.

- 

**[ConnectApi.DecisionTableBulkLookupOptions](./apex-connectapi-input-decision-table-bulk-lookup-options.md)**

Input representation of the lookup options for a versioned CSV decision table. The API ignores these options for any other decision table type.
