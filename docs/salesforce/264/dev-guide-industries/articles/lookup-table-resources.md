# Resources

Lookup Table API includes these resources.

- 

**[Decision Matrix Lookup (POST)](./connect-resources-bre-decision-matrix.md)**

Performs a lookup on decision matrix rows based on the input values provided, and returns the row’s output.

- 

**[Decision Model Notation Export (POST)](./connect-resources-bre-decision-model-entity.md)**

Export decision matrix data to a file in the DMN (Decision Model Notation) format, an easily readable format for business rules designed by Object Management Group.

- 

**[Decision Table Definitions (POST)](https://developer.salesforce.com/docs/industries/industries-common-dev/guide/connect-resources-decision-table-definition-details-post.html)**

Create a decision table definition. A decision table definition contains all the details required to create a decision table.

- 

**[Decision Table Definitions (DELETE, GET)](./connect-resources-decision-table-definition-details.md)**

Get details of a decision table definition. Delete a decision table definition associated with a decision table.

- 

**[Decision Table Definitions (PATCH)](https://developer.salesforce.com/docs/industries/industries-common-dev/guide/connect-resources-decision-table-definition-details-patch.html)**

Update a decision table definition associated with a decision table.

- 

**[Decision Table Lookup (POST)](./connect-resources-bre-decision-table.md)**

Performs a lookup on a decision table.

- 

**[Decision Table Invocation (POST)](./connect-resources-decisiontableid.md)**

Invoke a decision table by passing multiple input conditions within the same request.

- 

**[Lookup Tables (GET)](./connect-resources-bre-search-lookup-tables.md)**

Retrieve lookup tables.

- 

**[CSV Based Decision Table (GET)](./connect-resources-decision-table-csv-based-dt.md)**

Fetch paginated data from a CSV based decision table. This resource is responsible for managing rows in a Decision Table.

- 

**[Decision Table Execution](./connect-resources-decision-table-execution.md)**

Execute an active decision table.
