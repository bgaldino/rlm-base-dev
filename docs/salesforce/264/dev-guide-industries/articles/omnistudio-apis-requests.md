# Request Bodies

Here’s a list of Expression Set API (also known as Calculation Procedure) request bodies.

**Note:**

These APIs have been deprecated as of API version 55.0. In API version 55.0 and later, use the new [Business APIs in Business Rules Engine](https://developer.salesforce.com/docs/atlas.en-us.industries_reference.meta/industries_reference/business_rules_engine_connect_apis.htm).

- 

**[Calculation Procedure Version Definition Input](./connect-requests-calculation-procedure-version-definition-input.md)**

Input representation of the expression set version definition.

- 

**[Calculation Procedure Step Input](./connect-requests-calculation-procedure-step-input.md)**

Input representation for the expression set version steps.

- 

**[Resource Input](./connect-requests-resource-input.md)**

Input representation of the expression set resource (variable or constant).

- 

**[Simulation Config Input](./connect-requests-simulation-config-input.md)**

Input information of the configuration version to run a simulation.

- 

**[Simulation Evaluation Service Input](./connect-requests-simulation-eval-service-input.md)**

Input representation to run simulation on an expression set.

- 

**[Simulation Context Input](./connect-requests-simulation-context-input.md)**

Input representation of context details for simulation.

- 

**[Simulation Variable Input](./connect-requests-simulation-variable-input.md)**

Input information of the input variable and its value.

- 

**[Simulation Version Info Input](./connect-requests-simulation-version-info-input.md)**

Input information of the version details to run simulation.
