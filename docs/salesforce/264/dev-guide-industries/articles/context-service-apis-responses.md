# Response Bodies

Here’s a list of Context Service response bodies.

- 

**[Context Attribute Output](./connect-responses-context-attribute.md)**

Output representation of the context attribute.

- 

**[Context Attribute Mapping](./connect-responses-context-attribute-mapping.md)**

Output representation of the context attribute mapping.

- 

**[Context Attribute Mapping List](./connect-responses-context-attribute-mapping-list.md)**

Output representation of list of context attribute mappings.

- 

**[Context Attribute Hydration Detail](./connect-responses-context-attr-hydration-detail.md)**

Output representation of context attribute hydration detail.

- 

**[Context Attribute Tag Output](./connect-responses-context-attribute-tag.md)**

Output representation of context attribute tag.

- 

**[Context Attribute List Output](./connect-responses-context-attribute-list.md)**

Output representation of list of context attributes.

- 

**[Context Data Record](./connect-responses-context-data-record.md)**

Output representation of context data record, including its attributes, type, associated child objects, and other relevant metadata.

- 

**[Context Data Record Status](./connect-responses-context-data-record-status.md)**

Output representation of context data record status.

- 

**[Context Definition Filter](./connect-responses-context-definition-filter.md)**

Output representation details of a context definition filter.

- 

**[Context Definition Filter List](./connect-responses-context-definition-filter-list.md)**

Output representation details of context definition filter list.

- 

**[Context Definition Information](./connect-responses-context-definition-info.md)**

Output representation of context definition information.

- 

**[Context Definition Interface](./connect-responses-context-definition-interface.md)**

Output representation of the details of the context definition interface.

- 

**[Context Definition Interface Attribute Tag](./connect-responses-context-definition-interface-attribute-tag.md)**

Output representation of the attribute tags associated with the context definition interface.

- 

**[Context Definition Interface Metadata](./connect-responses-context-definition-interface-metadata.md)**

Output representation of the metadata associated with the context definition interface.

- 

**[Context Definition Interface Metadata List](./connect-responses-context-definition-interface-metadata-list.md)**

Output representation of the metadata list associated with the context definition interfaces.

- 

**[Context Definition Interface Node Tag](./connect-responses-context-definition-interface-node-tag.md)**

Output representation of the tags associated with the context definition interface.

- 

**[Context Definition Output](./connect-responses-context-definition.md)**

Output representation of context definition.

- 

**[Context Definition List](./connect-responses-context-definition-list.md)**

Output representation of list of context definitions.

- 

**[Context Definition Version](./connect-responses-context-definition-version.md)**

Output representation of context definition version.

- 

**[Context Definition Reference](./connect-responses-context-definition-reference.md)**

Output representation of context definition reference.

- 

**[Context Error Response](./connect-responses-context-error.md)**

Output representation of context error.

- 

**[Context Information](./connect-responses-context-info.md)**

Output representation containing detailed information about a context.

- 

**[Context Mapping Output](./connect-responses-context-mapping.md)**

Output representation of context mapping.

- 

**[Context Mapping List Output](./connect-responses-context-mapping-list.md)**

Output representation of a list of context mappings.

- 

**[Context Node Mapping Output](./connect-responses-context-node-mapping.md)**

Output representation of the context node mapping.

- 

**[Context Node Mapping List Output](./connect-responses-context-node-mapping-list.md)**

Output representation of list of context node mappings.

- 

**[Context Node List](./connect-responses-context-node-list.md)**

Output representation of the list of context nodes.

- 

**[Context Node](./connect-responses-context-node.md)**

Output representation of the details of context nodes.

- 

**[Context Output](./connect-responses-context-output.md)**

Output Representation of attributes associated with defined context.

- 

**[Context Query Record](./connect-responses-context-query-record.md)**

Output representation of context query record, including primary and associated child records.

- 

**[Context Tag Data](./connect-responses-context-tag-data.md)**

Output representation of context tag data.

- 

**[Context Tag Data Leaner](./connect-responses-context-tag-data-leaner.md)**

Output representation of the leaner context tag data. It stores only the metadata required to reconstruct tag values and the index references instead of full path strings.

- 

**[Context Tag List Output](./connect-responses-context-tag-list.md)**

Output representation of list of context tags.

- 

**[Leaner Query Tags Result](./connect-responses-leaner-query-tags-result.md)**

Output representation of the leaner query tags result. The result includes compact tag data mapped to tag names and a shared list of record IDs.

- 

**[Mapped Attribute Data Type](./connect-responses-mapped-attribute-data-type-info.md)**

Output representation of the context attribute mapping data type information.

- 

**[Persist Context Output](./connect-responses-persist-context-output.md)**

Output Representation to persist context data.

- 

**[Query Context Record Result](./connect-responses-query-context-record-result.md)**

Output representation of query result context record.

- 

**[Query Context Record Result Data](./connect-responses-query-context-record-result-data.md)**

Output representation of the query result for one data path.

- 

**[Query Records Result](./connect-responses-query-records-result.md)**

Output representation of the results when querying context records and their child records.

- 

**[Query Record Status Result](./connect-responses-query-record-status-result.md)**

Output representation of query result status of context data records.

- 

**[Query Tags](./connect-responses-query-tags.md)**

Output representation of query tags result.

- 

**[Query Tags Result](./connect-responses-query-tags-result.md)**

Output representation of the results when querying context tags.
