# Decision Explainer Business APIs

Use the Decision Explainer Business APIs to give users a seamless API experience for applications to audit their past events.

You can access Decision Explainer APIs using REST endpoints. These REST APIs follow similar conventions as Connect REST APIs.

To understand the architecture, authentication, rate limits, and how the requests and responses work, see [Connect REST API Developer Guide](https://developer.salesforce.com/docs/atlas.en-us.264.0.chatterapi.meta/chatterapi/intro_what_is_chatter_connect.htm).
