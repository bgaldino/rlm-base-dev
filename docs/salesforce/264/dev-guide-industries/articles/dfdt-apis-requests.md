# Discovery Framework API Requests

Here’s the list of the Discovery Framework Document Decision API request bodies.

- 

**[Assessment Details Input](./connect-requests-assessment-responses-assessment-details-input.md)**

Input representation of the assessment details of Assessment Response request.

- 

**[Assessment Links Input](./connect-requests-assessment-links-input.md)**

Associated assessments including id, category, reason and sequence.

- 

**[Assessment Reasons Input](./connect-requests-assessment-responses-assessment-reason-input.md)**

Input representation of the assessment reason in Assessment Response request.

- 

**[Assessment Responses Input](./connect-requests-assessment-responses-input.md)**

Input for assessment responses.

- 

**[Assessment Values Input](./connect-requests-assessment-responses-assessment-values-input.md)**

Input representation of the assessment value of Assessment Response request.

- 

**[Document Decision Input](./connect-requests-document-decision-input.md)**

Input representation of the Document Decision request.

- 

**[Question Responses Input](./connect-requests-question-responses-input.md)**

Input for assessment question responses.
