# Generate Context-Rich Sequence Patterns with Dynamic Fields

Embed standard or custom fields from target objects, such as invoice and credit memo, into sequence patterns to encode business context into sequence numbers. Combine dynamic fields with static text to create numbering formats that support compliance and operational requirements.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Billing license.

Who: To create sequence policies, you need the Billing Admin permission set.

How: From Setup, use the Quick Find box to find and select Billing Settings. To assign sequential numbers to invoice records, configure gapless sequential numbering for Billing.

To create sequence policies, from the App Launcher, find and select Sequence Policies. When you define sequence patterns for the selected target object, select fields to include in the pattern.
