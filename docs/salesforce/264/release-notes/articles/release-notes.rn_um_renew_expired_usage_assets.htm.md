# Win Back Customers by Restoring Lapsed Subscriptions

Restore service when usage subscriptions expire and bring back customers with updated rates and grant quantities. Preserve the asset history for reporting continuity.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Advanced license.

Note: Late renewal isn't available in orgs that have both the Revenue Cloud Advanced and Revenue Cloud Billing licenses with the Usage Management add-on.

How: From an expired usage asset, create a renewal quote and select Override Renewal Term. Select a start date on or after the asset expiration date.
