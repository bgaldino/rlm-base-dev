# Orchestrate High Tech Order Scenarios by Using a Prebuilt Template

Extend Dynamic Revenue Orchestrator with a preconfigured orchestration plan in Salesforce Go that’s built for common high tech order scenarios. Skip the manual setup work and start from a template designed around industry-specific order orchestration.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Advanced or Revenue Cloud Billing license.

How: Select Salesforce Go from the gear menu or from the main Setup menu. Select Revenue Cloud and filter the content type dropdown by Data Packs to view and set up High Tech Order Orchestration Template.
