# Changed Objects in Dynamic Revenue Orchestrator

Do more with these changed Dynamic Revenue Orchestrator objects.

Changed Objects
Specify the name of the custom scope when the dependency scope is set to custom
Use the new CustomScope field on the existing FulfillmentStepDependencyDef object.
Specify the description of the fulfillment step definition, shown to admins in the orchestration plan
Use the new Description field on the existing FulfillmentStepDefinition object.
Specify the scope under which the fulfillment step was created
Use the new ScopeIdentifier field on the existing FulfillmentStep object.
