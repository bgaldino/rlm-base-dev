# Prevent Usage Summary Failures by Updating Overridden Flows

Update your overridden Usage Management flows to use version 4 of the Data Processing Engine (DPE) definitions and prevent usage summary failures. Version 3 DPE definitions are no longer supported and can’t be opened, edited, or run.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Advanced license.
