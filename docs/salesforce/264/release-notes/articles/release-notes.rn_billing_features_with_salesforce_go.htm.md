# Configure Billing Features Faster

Use Salesforce Go to discover and configure Invoice Management, Tax Calculation, Invoice Document Delivery, and Accounting Sub-Ledger for Accounts Receivables. Guided setup steps, videos, and help resources walk you through configuration so you spend less time configuring these Billing features.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Advanced or Revenue Cloud Billing license. Invoice Document Delivery is only available with the Revenue Cloud Billing license. The Revenue Cloud Advanced license includes a few features of Accounting Sub-Ledger for Accounts Receivables.

How: To view the Salesforce Go offerings in Revenue Cloud, select Salesforce Go from the gear menu or from the main Setup menu, and select Revenue Cloud.

In the content type dropdown, filter by Feature to set up any of these features, or filter by Feature Set and select Manage Billing to set up all these Billing features.

Select Invoice Management to set up automated invoice generation, billing policies, payment terms, and credit rules.
Select Invoice Document Delivery to generate and email invoice documents with customizable templates.
Select Tax Calculation for tax policies, treatments, and tax engine integrations to calculate taxes during invoicing and credits.
Select Accounting Sub-Ledger for Accounts Receivables to automate the generation of transaction journals and period end summaries.
