# Set Invoice Target Dates by Calendar Day or Billing Period Count

Adapt invoice processing for complex billing scenarios with dynamic target dates in invoice batch runs and Invoice API. Set target dates based on a specific calendar day of the month or a fixed number of billing periods instead of static day offsets.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Advanced or Revenue Cloud Billing license.

Who: To schedule invoice runs, you need the Billing Admin or the Billing Operations User permission set.

How: From the App Launcher, find and select Billing Batch Scheduler. Create an invoice scheduler, or edit a draft or inactive one, and set the target date by calendar day of the month or by a fixed number of billing periods.
