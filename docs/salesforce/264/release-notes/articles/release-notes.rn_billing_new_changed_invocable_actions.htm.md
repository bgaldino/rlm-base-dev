# New and Changed Invocable Actions in Billing

Automate refund and billing schedule workflows with a new invocable action, and get asynchronous execution support in existing invocable actions for billing schedule creation.

Process refunds against posted credit memos
Use the new processRefundCreditMemo action.
Process billing schedule creation requests asynchronously
Use the new executeAsync input parameter on the existing createBillingSchedulesFromBillingTransaction action.
Process standalone billing schedule creation requests asynchronously
Use the new executeAsync input parameter on the existing createBillingSchedulesFromTrxn action.
