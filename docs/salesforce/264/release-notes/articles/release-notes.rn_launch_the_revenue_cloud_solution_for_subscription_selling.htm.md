# Launch the Revenue Cloud Solution for Subscription Selling

Install the Revenue Cloud Subscription Selling solution in an empty sandbox from Salesforce Go with a working reference configuration. The installation turns on Revenue Cloud foundations and configures your org with sample subscription products, price books, and more, giving you the experience of a Revenue Cloud implementation for subscription-selling use cases. Start quoting and placing orders immediately with a baseline configuration. Use this solution as a starting point, and then refine the configuration for your production rollout.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Cloud, with the Revenue Cloud Advanced license.

This solution is available only in sandboxes.

How: Select Salesforce Go from the gear menu or from the main Setup menu. Select Revenue Cloud. In the content type dropdown, filter by Get Started to view and set up the Subscription Selling Solution.

Select either Standard Installation or Custom Installation to begin. After installation, grant your sales reps the required access. Then, use the sample product selling models, quotes, and orders to review the reference configuration before adapting it to your business.
