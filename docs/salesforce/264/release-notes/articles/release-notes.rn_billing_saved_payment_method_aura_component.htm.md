# Manage Saved Payment Methods in Aura Experience Sites

Add the Saved Payment Methods for Aura component to any Experience Cloud site built by using Aura templates. Your customers can add, view, delete, or set a saved payment method as the default for their account on the site for faster and frictionless payments.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Cloud, formerly Revenue Cloud, with the Revenue Cloud Billing license.

Who: Your users need the Billing Experience Cloud User permission set to use the Aura components in Experience Builder.

How: To add these components to your pages, open your Experience Cloud site in Experience Builder. In the components palette, under the Layout section, find the Saved Payment Methods for Aura component, and drag it onto your page. Configure the component and republish your site.
