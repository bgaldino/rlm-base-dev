# Track Recipient Signing Progress for Document Envelopes

Know exactly where a contract is in the signing process and keep deals on track. Update an envelope's status to view each recipient's signing progress for the contract.

Where: This change applies to Lightning Experience in Enterprise, Performance, Unlimited, and Developer editions of Agentforce Revenue Cloud, formerly Revenue Cloud, with the Revenue Cloud Advanced or Salesforce Contracts license.

How: To view an envelope’s details and status, on a contract record, click Update Envelope Status.
