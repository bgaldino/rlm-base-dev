# Preview Future Invoice Charges with Billing Forecast

Get full transparency into projected billing charges before invoices are created. Run scheduled forecasts for one-time and subscription charge types and categories. Use forecast data to align with customers on upcoming charges and report on projected billing.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Billing license. To view the Billing Forecast Console, you need the Tableau Next Consumer license.

Who: To enable Billing Forecast, you need the Billing Admin permission set. To create and manage forecast schedules, you need the Billing Operations User permission set.

How: From Setup, use the Quick Find box to find and select Billing Settings, and turn on Billing Forecast. To schedule a forecast run, from the App Launcher, find and select Billing Batch Scheduler. Click New Billing Forecast Scheduler and configure your forecast schedule. To view projected billing details, access the Billing Forecast records directly. You can also view the projected details by completing the required Tableau setup and accessing it through the Billing Forecast Console.
