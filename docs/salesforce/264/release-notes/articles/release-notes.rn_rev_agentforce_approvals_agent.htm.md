# Accelerate Approval Decisions with Approval Agent

Sales reps can now manage approval workflows with the Approval Agent. They can submit and recall approval submissions, track pending approvals. Reviewers can retrieve submissions, generate AI-assisted summaries and comments, and approve or reject submissions faster.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions where Advanced Approvals and Agentforce are enabled.

When: Approval Agent is available starting the week of September 14, 2026.
