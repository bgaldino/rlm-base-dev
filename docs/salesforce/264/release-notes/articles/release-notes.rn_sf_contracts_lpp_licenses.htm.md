# Use Salesforce Contracts with Lightning Platform Licenses

Now you can pair Salesforce Contracts with Lightning Platform Starter or Lightning Platform Plus, reducing licensing costs for organizations that need contract lifecycle management without full CRM capabilities. Some Salesforce Contracts capabilities depend on features that aren't included with Lightning Platform licenses. Previously, Salesforce Contracts required a Core CRM license, such as Sales Cloud or Service Cloud.

Where: This change applies to Lightning Experience in Enterprise, Performance, and Unlimited editions of Agentforce Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Advanced, or Salesforce Contracts license.

Who: To use Salesforce Contracts, you need a Core CRM license (Sales Cloud or Sales and Service Cloud), a Lightning Platform Starter license, or a Lightning Platform Plus license. Contact your Salesforce account executive for more information.

How: Assign a Salesforce Platform or Salesforce Platform Login user license and the CLM Admin User or CLM Runtime User permission set to your user. Additional setup includes profile configuration, object permissions, and sharing settings. See Set Up Salesforce Contracts for Lightning Platform Licenses.
