# Promotions in Revenue Management

Pricing designers can set up promotions that users apply to transactions. Developers can use objects and APIs to manage promotions on sales transactions.

Increase Sales with Promotions in Revenue Management
Create manual and automatic promotions that discount individual products or entire categories. Target the right buyers by defining promotion eligibility with rules and sales channels. Control discount stacking by specifying how to evaluate multiple promotions that apply to the same transaction. Manage promotions on sales transactions programmatically with objects and APIs.
New and Changed Objects for Promotions in Revenue Management
Store and access promotion-related data with these new objects and changes to existing Agentforce Revenue Management, formerly Revenue Cloud, objects.
