# Generate Invoice Documents Automatically During Invoice Batch Runs

Create invoice documents automatically as invoices are streamed during a batch run, eliminating the need for a separate document generation step.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Cloud, with the Revenue Cloud Billing license.

Who: To schedule invoice runs, you need the Billing Operations User permission set. To generate invoice documents during a batch run, you need the DocGen User permission set.

How: From the App Launcher, find and select Billing Batch Scheduler. To modify draft or inactive invoice schedulers, edit the scheduler and select Generate invoice documents. You can also create invoice schedulers that include invoice document generation.
