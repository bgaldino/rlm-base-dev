# Generate Documents for Quotes with 15,000 Line Items

Create PDFs that accurately capture complex product hierarchies in large quotes. CLM Document Generation supports quotes with up to 15,000 line items, 1,000 bundles, and 5 levels of nested grouping.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Growth or the Revenue Cloud Advanced license.

How: Set up a quote document template and add the Document Generation quick action to the Quote page layout. Sales reps use the quick action to generate quote documents, which are automatically added to the Quote PDFs related list on the quote record.
