# Review All Impacted Split Invoices Before Posting, Voiding, or Deleting

See all related split invoices before acting on an invoice created through a billing arrangement. The Split Invoices tab on the Invoice page shows all linked invoices across accounts. Actions taken on one split invoice trigger the same action on all related invoices. This visibility prevents unintended financial consequences when posting, voiding, or deleting split invoices.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Billing license.

Who: To view all related split invoices, you need the Billing Admin or the Billing Operations User permission set.

How: From the Invoice page, open the Split Invoices tab to view related split invoices.
