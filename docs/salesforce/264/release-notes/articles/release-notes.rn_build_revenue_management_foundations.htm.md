# Build Revenue Cloud Faster with Prebuilt Design Foundations

Install Revenue Cloud capabilities and select prebuilt components for common implementation work. Add sample usage products and rate cards, refresh product qualification, pricing, and rating rules, or start orchestration when an order activates. You spend less time assembling a working implementation.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Cloud, with the Revenue Cloud Advanced license.

How: In Salesforce Go, click Revenue Design Foundations. Select Custom Installation to select optional sample usage products and rate cards, flows that refresh product qualification, pricing, and rating rules, and a flow that submits the order to Dynamic Revenue Orchestrator when the order activates. Review and adapt the installed components in a sandbox before using them for your business processes.
