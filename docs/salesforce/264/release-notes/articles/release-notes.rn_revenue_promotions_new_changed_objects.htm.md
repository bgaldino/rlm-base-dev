# New and Changed Objects for Promotions in Revenue Management

Store and access promotion-related data with these new objects and changes to existing Agentforce Revenue Management, formerly Revenue Cloud, objects.

Create a junction between an asset and a promotion that’s applied to the asset
Use the new AssetActionSrcPriceAdjustment object.
Specify the date and time when a promotion is applied to an order item
Use the AppliedPromotionDate field on the existing OrderItemAdjustmentLineItem object.
Specify the coupon code to apply a manual promotion to an order item
Use the CouponCode field on the existing OrderItemAdjustmentLineItem object.
Specify the date and time when a promotion is applied to a quote line
Use the AppliedPromotionDate field on the existing QuoteLinePriceAdjustment object.
Specify the coupon code to apply a manual promotion to a quote line
Use the CouponCode field on the existing QuoteLinePriceAdjustment object.
