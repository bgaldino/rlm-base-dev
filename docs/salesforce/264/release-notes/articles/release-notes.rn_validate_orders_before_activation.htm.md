# Validate Orders Before Activation

Apply configurable activation checks before an order becomes active. An activation gate keeps orders from moving forward until they satisfy your conditions.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Cloud, with the Revenue Cloud Advanced license.

How: In Salesforce Go, click Quote to Order Conversion. Install Order Activation Gate Checks in a sandbox.
