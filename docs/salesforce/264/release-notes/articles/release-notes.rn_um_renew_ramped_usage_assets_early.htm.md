# Respond to Growth with Early Ramp Renewal

When customers with ramped pricing need to renew early, start the term at any point in their current schedule: year 1, year 2, or later. The renewal automatically extends coverage beyond the original end date, recreates subsequent segments with updated dates and the latest catalog rates.

Where: This change applies to Lightning Experience in Enterprise, Unlimited, and Developer editions of Revenue Management, formerly Revenue Cloud, with the Revenue Cloud Advanced license.

How: From an active ramped usage asset, create a renewal quote and select Override Renewal Term. Select a start date during the current asset lifecycle.
