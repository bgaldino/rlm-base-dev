> ⚠ **The `Impacted Plans` column matches on object name only.** A plan appears here
> because it touches the object, not because it references the changed field — so a

> query *and* its CSV header. Three rows below said "remove `<field>` from the CSV
> headers" for fields no maintained CSV contained; two were false positives outright,
