# MeshMesh recipes

One directory per recipe. `recipe.md` sits at the root of that directory, next to the config, sample-data, metadata, and PDF files the recipe uses.

```text
recipes/meshmesh/<recipe-name>/
  recipe.md
  config-defaults.json
  sample-data-generator.md
  ...
```

Name the directory in lower-kebab-case. Drop browser download suffixes such as ` (1)` from the folder name before adding it.
